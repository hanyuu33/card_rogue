## 二、判定方法（可复现，不靠手感）

对每张图算四个统计量：亮度均值 `L`、亮度标准差、饱和度、暗像素占比 `dark`（L<60）、高光占比 `hi`（L>200）。门限由 2026-11-24 的 16 张新水彩基准图与全库抽检标定：

```
A_ok   dark < 0.12 且 L > 135 且 hi > 0.08   新基准图实测 L=140~184、dark<=0.08、hi>=0.11
C_fix  dark >= 0.12 或 L <= 120              旧图实测 L=45~119、dark 0.11~0.79、hi<=0.06
其余                                          灰区，进人工复核
```

**已知局限**：白底写实渲染（如 9142 白底无人机）统计量会贴近亮调水彩，故 A 类必须目检。本轮已对 25 张 A/灰区样本逐张目检，结论写进 `Review` 列。
