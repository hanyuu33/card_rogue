## ⚠️ 关键教训：俄倪厄形象纠正

- 最初 prompt 把俄倪厄主体写成了「希腊神像风格的青铜机械构装体」，codex 读图发现
  实际是**白发兽耳持剑少女**，当场停下来问。
- 一度误判为「错图」（因为 traits 含「机械」、且量产型 9131 是四足机械兽）。
- **店长澄清**：形象设计没问题，**本体都是人形，量产型才是纯工具机械**；卡图基本
  形象店长都把关过。→ 结论：**重出时主体必须保持原样，只动「写实厚涂 → 赛璐璐」，
  不许擅自改主体形态。**
- 俄倪厄正确定义：银白高马尾长发、青蓝眼、白兽耳 + 白兽尾、深灰无袖作战服 + 破旧灰斗篷
  + 工装裤 + 军靴、双手持长剑挥斩，无机械义肢，气质冷峻。

## 风格判据（本轮唯一要改的）

日式动漫赛璐璐：干净深色线稿、硬边阴影、清晰外轮廓描边、主体亮背景暗、高饱和集中在主体；
**禁**写实厚涂 / 3D 渲染 / 油画水彩 / 噪点颗粒 / 照片级金属反光 / 柔和渐变 / 光追反射。

## 巴兰关三单位（α/β/γ）出图与修复

- 9237 巴兰-α 由 codex 出图（赛璐璐）。
- 9238 安西-β、9239 塔基尼-γ 因 codex 没额度，最初用 ImageGen **图生图**（以 9237 作风格参考，
  `input_fidelity=low`）。**但 image1 是「整体参考」，把 9237 的「正面静止站桩」姿势也抄了过来**，
  抹平了 β/γ 各自的「马步动感」——店长报「全都学成参考图的姿势了」。
- **修复**：9238/9239 改**纯文字 prompt**（不传 image1），风格用文字精确描述赛璐璐，姿势各自写回原本动作：
  - 9238 = 马步深蹲 + 右臂屈肘抬加特林朝前下方 + 左机械爪外张；
  - 9239 = 马步 + 双手胸前横持长炮斜指左上 + 左腿前伸右腿后。
- ⚠️ ImageGen 默认在右下角加「AI生成 WORKBUDDY>」水印 → 用 buddy-image-processing `erase` 去除。
  教训：曾试手写 PIL 按亮度扫水印 bbox，扫到机甲高光、填充错位打成补丁 → 作废重生成；去水印别手写，用 `erase`。
- **铁律**：图生图（image1）会连姿势一起抄，要「只借风格」必须**纯文字 prompt**，风格与姿势都用文字精确描述。
- 三张最终风格统一、姿势各异（巴兰站桩平举炮 / 安西前倾马步 / 塔基尼马步斜扛炮），同批 swap 进主目录。
