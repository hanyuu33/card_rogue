# 2026-10-31 洞穴战斗背景（R468）

槽位：`assets/ui/battle_bg_cave_owlbear.png` —— 关卡 key = `cave_owlbear`，
`UiAssets.battle_bg_path()` 第一级就命中，从此洞穴关不再回退到第二层地图底图 `map_bg_2.png`。

## 为什么需要这一张

`battle_bg_path()` 是三级回退：

1. `assets/ui/battle_bg_<关卡key>.png` —— 本关专属
2. `assets/ui/map_bg_<层号>.png` —— 当层地图底图
3. `assets/battle_bg.png` —— 全局兜底

洞穴关 `layer = LAYER_TWO` 又没有专属图，所以一直落在第 2 级 = 第二层的工业蒸汽底图。
（三层也摇得到洞穴事件 —— 三层 `content_layers = [2, 3]`，但背景取的是**关卡自报层** 2，
不是玩家当前所在层，所以从三层进洞也是同一张工业图。有了专属图后三条入口统一。）

## 文件

- `raw/` —— 原图（1280×720，右下角带生成水印，不直接用）
- `battle_bg_cave_owlbear_定稿1280x720.png` —— 定稿：裁掉底部 50px（水印落区 y≈675~715），
  再按 16:9 裁左右到 1191×670，最后等比放大回 1280×720（无变形）

## 构图约束（后续重画照这个来）

- **景物压四周、中央留空**：洞壁 / 石钟乳 / 钟乳石柱都在边框区，中间一大片平岩空地给棋盘
- 明度偏低、中央低对比度 —— 上面要压战场网格、手牌、按钮
- 光源：洞顶破口的暖色光柱斜射，落点在中央，不抢视觉重心
- 暗部点缀：青蓝色发光蘑菇 + 蕨类，避免纯黑一片
