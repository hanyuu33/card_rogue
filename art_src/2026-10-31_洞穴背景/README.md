## 为什么需要这一张

`battle_bg_path()` 是三级回退：

1. `assets/ui/battle_bg_<关卡key>.png` —— 本关专属
2. `assets/ui/map_bg_<层号>.png` —— 当层地图底图
3. `assets/battle_bg.png` —— 全局兜底

洞穴关 `layer = LAYER_TWO` 又没有专属图，所以一直落在第 2 级 = 第二层的工业蒸汽底图。
（三层也摇得到洞穴事件 —— 三层 `content_layers = [2, 3]`，但背景取的是**关卡自报层** 2，
不是玩家当前所在层，所以从三层进洞也是同一张工业图。有了专属图后三条入口统一。）

## 提示词写法上的经验（比“景物压四周”更要紧）

正面写「中央留空」会被画成**几何地台**；正面写「向深处收拢」会被画成**走廊**。要改成
**否定式 + 具体物件**：

- 不要写「一大片平坦空旷的岩石地面」→ 写「连续延伸的天然岩床，没有圆形轮廓 / 没有独立地台 /
  没有闭合边缘线 / 没有台阶」，再用「自然过渡为碎石、苔痕和阴影」收边
- 不要写「向画面深处自然收拢成暗部」→ 写「后壁在中景就被崩塌碎石堆封死，远景是岩壁本体，
  没有走廊 / 没有隧道 / 没有通道开口」
- 不要写「错落分布的石笋」→ 会画成齿列。写「只有三四块粗矮岩石，位置随机、彼此远离，
  不要成排的尖细石笋」
- 光源数量要写死：「全画面只有一个光源」，并逐个否定「没有天窗 / 没有露天裂口 / 没有多个透光孔」

## 构图约束（后续重画照这个来）

- **景物压四周、中央留空**：洞壁 / 钟乳石 / 碎石堆都在边框区，中间连续岩床给棋盘
- 中央低对比度、明度中灰偏亮 —— 上面要压战场网格、手牌、按钮
- 光源：洞顶偏右上一道窄裂隙的暖色光柱斜射左下，落点在中央，不抢视觉重心
- 暗部点缀：青蓝色发光蘑菇 + 蕨类，避免纯黑一片
- 生成图右下角固定带「AI生成 / WORKBUDDY」水印，落区随尺寸变化，裁前先放大右下角量一次
