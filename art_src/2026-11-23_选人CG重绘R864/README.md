## 五、顶部留头：直接缩放会切头（R864b 修正）

第一版是「1672×941 等比缩放到 1280×720」，实机一看**人物头顶被标题栏啃掉**。
原因不是裁切过头，而是两头夹：

1. `class_pick_scene._draw()` 用 `CardFace.cover_region_top()` 把 CG **顶部优先铺满整窗**；
2. 窗口最上面还压着一条 30px 的标题栏（「选择你的角色」）；
3. 源图本身是 16:9，人物头顶离**源图顶边**只有 5~8% 卡高 —— 缩完正好落在标题栏底下沿。

裁切救不了：源图已经没有更高的空间可取，任何裁法都只会更切头。所以改成
**补一条顶部延伸带 + 整体下移**：

```
源图 → 缩放 1280×720
     → 取最上 48 行，上下翻转，压成 1280×40，高斯模糊 12px     ← 延伸带
     → 画布 1280×720：延伸带贴顶，原图下移 40px，底部等量裁掉
```

- 翻转 + 模糊之后，森林的树影 / 废墟的夜空 / 工坊的木梁都能自然接上，
  看不出是补的（`HEAD_ROOM` 40px 只占卡高 5.5%，糊一层就全是色块）。
- 底部裁掉的 40px 本来就被底部头像行压着，不损失信息。
- 落点：`assets/ui/class_cg_<kind>.png`，仍为 1280×720，绘制侧代码**一行没改**。

脚本 `_apply_cg.py` 就是这套流程，改 `PICKS` 里的 `head_room` 可以单张微调。
以后换 CG 直接改 `PICKS` 重跑，不要再手工 resize。
