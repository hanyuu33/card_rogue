| 选项 | 结果 |
| --- | --- |
| 推门进去（传奇道具 ＋ 史诗卡牌，代价是「诅咒娃娃」） | 一件随机**传奇**道具 + 一组**史诗**卡牌三选一，**当场弹出奖励页**；同时强制一张「诅咒娃娃」进卡组；本事件收成「离开」 |

## 「没有战斗胜利标记的奖励页」是怎么做到的

战斗那边的链路是：

```
胜利 → battle_scene._present_win_panel()   ← 金框 + 大字「战斗胜利」+ 金币行
     → 点「查看奖励」→ _on_win_primary() → _reward_panel.open()
```

事件这边**直接调 `_reward_panel.open()`**，整条胜利面板链路根本不经过：

```
探索 → RunState.queue_relic_reward() / queue_card_reward("epic")
     → RunState.add_card(9276)
     → _reward_panel.open()        ← 打开的就是奖励列表页 / 三选一页
```

事件页本来就已经挂了一个 `RewardPanel`（`_ready` 里 `RewardPanel.attach(self, Vector2(12, 40))`，
宝箱 / 奥秘之泉都在用它），所以这次不用新建，直接复用。

两条纪律：

1. **必须先入队再 `open()`** —— `open()` 读的就是 `RunState.pending_rewards`，空队列开出来是空页；
2. **不替玩家领** —— 关窗时没领的条目跟着地图左上「✦ 待领奖励」走（R695 口径），
   玩家有权不拿直接过。

## 诅咒娃娃 9276

```
诅咒 · 0 费 · rarity 6 · unplayable · affixes ["保存"]
不能打出。回合结束时，你受到 3 点伤害。
回合开始时，若这张卡在弃牌区，这张卡从弃牌区加入你的手牌。
```

三条机制在引擎里：

| 时机 | 实现 | 位置 |
| --- | --- | --- |
| 回合结束，它还在手牌 | `_curse_doll_tick()` → `_damage_player(SIDE_SELF, 3×张数, "诅咒娃娃")` | `end_turn()` 里，排在 `discard_hand()` **之前** |
| 回合开始，它在弃牌区 | `_curse_doll_return()` → 逐个 `_grant_to_hand()` | `_begin_turn()` 里，排在抽牌之前 |
| 不可打出 | `CardData.unplayable` | `play_from_hand()` 已有兜底（麻痹 9185 同一口） |

设计要点：

- **`保存` 让它常驻手牌**，所以「回合结束扣血」实际上每回合都会触发；
- 「弃牌区回手」是它**甩不掉**的原因：玩家想办法把它丢进弃牌区，只能躲开**那一次**扣血，
  下个我方回合开始它自己就爬回来；
- 伤害走 `_damage_player()` 唯一口，所以 lucky 7 的免疫、鸭嘴减伤、不锈钢盆、死亡判定
  全部照旧生效 —— 在上层再加一层减伤只会让那些道具白拿；
- 回手走 `_grant_to_hand()` 唯一口，**手牌满时它会留在弃牌区**（不静默消失、不突破 HAND_LIMIT）。

## 随机传奇：`RunState.roll_legendary_relic()`

新加的口。与 `roll_reward_relic()` 的分工：那个按「5% × 层数」摇档位，这个**直接锁死传奇档**。

- 传奇池空返回 **-1**，**不回落一般池** —— 悄悄塞一件一般的进去，卡面承诺的「传奇」就成了假话；
- 只消耗**一个** `randi`（不先摇 `randf` 判档），同一 seed 的道具序列不会凭空错位。
