# 机械之心 CG / 小头像 重做定稿（2026-11-06）

> 唯一权威依据。出图前先读本文件；本文件与 `ART.md`「机械之心角色正典」冲突时，以本文件为准。

## 一、重做动机

- 现状 CG（`assets/ui/class_cg_mech.png`）= 抱书的「图书馆少女」，黑发眼镜娘，背景图书室，
  **没有任何机械/工程元素**，与职业名「机械之心」及卡牌主题（素体/构装体/机兵/改造/维修）
  完全脱节。
- 小头像（`class_avatar_mech.png`）虽有「环形数据瞳」的科技细节，但与 CG 气质不一致，且环形瞳
  违反 ART.md「不许环瞳」口径（见下）。

## 二、用户既定口径（本轮确认，不可违背）

1. **尽可能像人**，机械只是细微特征，不做义体、不做机娘、不做重机甲。
2. **气质 = 冷静技术宅**（干练、理性的工程师/研究者气质，不是元气、不是柔弱）。
3. **机械特征强度 = 几乎不露机械**：只有眼镜、工具、领口发光核心吊坠、小无人机等点缀，本质普通人。
4. 重做范围 = **CG 立绘 + 小头像一起**。
5. 美术风格：由我判断，向游戏整体风格靠拢（日式动漫赛璐璐，与森林精魄 / 暗影刺客协调）。

## 三、与 ART.md 既有正典的衔接（必须继承）

ART.md「机械之心角色正典」已定（R438 用户口径），本轮 CG 是它的延伸而非推翻：

- 主角底色：**黑长直 + 圆框眼镜**（继承，不换发色，区别于其它机械之心人形卡）。
- 人形角色**不靠「机械感」标识身份**：眼睛就是**人类眼睛**，
  `NO 发光瞳 / NO 青色环瞳 / NO 护目镜 / NO 护目片 / NO seams / NO armor plating / NO exposed joints`。
- 身份靠**画面叙事**（她正在做什么）交代。

> 注意：小头像现版本的「环形数据瞳」违反上述口径，重做时一并去掉，改回人类眼睛。

## 四、最终人设定稿

| 元素 | 设计 |
|---|---|
| 身份 | 机械工程师 / 改造者，工坊主人（与「维修间 / 拆解 / 回收 / 升级」卡面语义一致） |
| 发型发色 | 黑长直（可微卷），束成低马尾或披肩；留海齐眉 |
| 眼睛 | 人类眼睛，大眼；虹膜**淡冰蓝（pale ice blue）**——浅色但不发光、不霓虹、无环纹（R438 口径） |
| 眼镜 | 圆框 / 椭圆细框眼镜（银灰或深色细框），标志性元素 |
| 服装 | 米白/浅棕工装（机能感，非脏旧粗布）：衬衫 + 工装背带裤或轻机能外套；**不要深灰工装背心**（R439 反面词） |
| 细微机械（克制） | ① 领口一枚**青蓝发光机械核心**吊坠（唯一「发光」元素，点题「机械之心」）；② 手边/肩上一个小型**维修无人机**；③ 工具 |
| 道具 | 扳手 / 螺丝刀 / 焊枪（呼应「维修间」），或正在给一台构装体接线 |
| 配色 | 黑发 + 米白工装 + 冷灰机械 + **一点青蓝发光**（与卡牌蓝光核心统一，占 5% 内） |
| 气质 | 冷静、专注、理性，眼神平静，不笑不卖萌（技术宅的「沉稳」，不是「阴沉」） |
| 场景 | 机械工坊 / 整备间：工作台、散落齿轮、待修构装体、暖黄台灯 + 青蓝机械冷光、湿反光金属地板 + 顶部灯带（R440 场景口径） |
| 画风 | 日式动漫赛璐璐，硬边阴影、薄线稿（人物卡走赛璐璐，与 R440 一致） |

### 关键动作（画面叙事核心）

不要「站着摆 pose」，要让她**正在做一件机械相关的事**（R438「身份交给画面叙事」）：
- 推荐：**半俯身，手持螺丝刀/焊枪，正在给一台半开的构装体胸口接线**（呼应卡图 8027「升级」里
  那个修机器人的女工程师，气质延续但更冷静干练）。
- 领口机械核心吊坠发着微光，暗示「心」。

## 五、三个职业 CG 的风格区分（协调性）

| 职业 | 色调 | 气质 | 背景 |
|---|---|---|---|
| 森林精魄 | 暖（蜜茶/墨绿/暖橘） | 天真自然精灵 | 阳光森林 |
| 暗影刺客 | 暗紫红灰蓝 | 冷冽神秘 | 夜间屋顶/城镇 |
| **机械之心** | **黑发 + 米白 + 冷灰 + 青蓝点缀** | **冷静理性技术宅** | **机械工坊/整备间** |

三者在「色温 + 场景」上天然区分，不撞。

## 六、小头像规格

- 同 CG 同一角色（黑发眼镜娘、淡冰蓝眼、圆框眼镜）。
- 头部/肩部特写，透明底（沿用暗影刺客头像的 flood-fill 抠白底流程）。
- **去掉环形数据瞳**，改人类眼睛。
- 保留「冷静」表情。

## 七、出图流程（沿用暗影刺客成熟流水线）

1. 文生图先出 CG 全身立绘（带工坊背景），多版迭代到定稿。
2. 定稿后出小头像（图生图，image1=定稿CG，只借角色设计）。
3. 落地 `assets/ui/class_cg_mech.png` + `class_avatar_mech.png`，原图 `.bak_*` 备份。
4. `--headless --import` 重建 .ctex。
5. 用户游戏内验收后，再考虑是否同步 git。

## 八、已确认（本轮锁定）

- 场景色调 = **暖台灯 + 冷机械光**（机械工坊，有温度、有人味，非全冷光整备间）。
