# R841c · 润滑油 7019 图标改机械风格

店长原话：「润滑油：做成机械用的风格」。

上一版（R841）画的是**玻璃瓶 + 软木塞 + 琥珀油**，读起来更像药水/橄榄油。
这一版改成**车间里给机器上油的老式金属油壶（oiler）**：黄铜罐身 + 深灰钢箍 + 铆钉 +
顶部按压泵杆 + 长弯金属嘴 + 嘴尖挂一滴油 + 罐身油污划痕。

## 提示词

`prompts/7019_oil_mech.txt`（纯英文，见下）

## 设计口径

- **「机械用」靠三件东西立住，缺一件就退化成厨房油壶**：
  ① 顶部**按压泵杆**（thumb-press lever）—— 手动油壶的标志件；
  ② **长而细的弯嘴**（long thin curved spout）—— 能伸进轴承/齿轮缝隙；
  ③ **罐身油污与划痕**（grease smudges / scratch）—— 「用过」的痕迹比造型更能说明用途。
- **材质给黄铜 + 钢，不给纯钢**：全套图标都是暖色赛璐璐，纯冷灰金属在 44px 下会和背景脱开；
  黄铜暖金正好接上既有暖色调，深灰钢箍负责把「金属感」压出来。
- **负面词必写**：`glass bottle / potion / wine bottle`（防退回上一版），
  `watering can`（长嘴容易被画成浇花壶），`plastic jerrycan`（防成塑料油桶），
  `green liquid`（防成药水），`gears scattered around`（单物件图标不许带配件）。
- **不画「滴油动画」那种连环油滴**：44px 下会糊成一串点；只留嘴尖**一滴**，与旧版同样的收束。
- 画风约束照抄全家族：厚描边、平涂赛璐璐 2~3 阶、纯白底、单物件居中、无地面阴影。
