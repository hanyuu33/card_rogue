## 出图方式（与之前 ImageGen 图生图的差别）

| 项 | 做法 |
|---|---|
| 出图工具 | `codex exec --json -i <参考图>` → codex 内置 `image_gen` |
| 参考图角色 | 只在首句声明「只借画风 / 只借角色设计」，内容全部重写 |
| 保真度 | codex 的 GPT Image 输入**恒为高保真**（没有 `input_fidelity` 参数），所以「只借画风」必须靠 prompt 文字切割，不能靠参数 |
| 代理 | 必须 `HTTP(S)_PROXY=http://127.0.0.1:7897`（系统 Clash）；环境自带的 63248 沙箱代理连不上 chatgpt.com（HTTP 502） |
| 取图 | codex 沙箱内拷不出文件，图落 `~/.codex/generated_images/<thread>/exec-*.png`，由 `_run_batch.py` 解析 JSONL 复制到 `raw/` |
| 后处理 | `python tools/cardart_prep.py <raw图> <id>` → 448×403 进 `assets/pics/_pending/` |

## 返工记录（4 张）

8083 / 9220 / 9221 / 9222 首版是「紧贴画框的全身构图」，448×403 裁窗要切掉上下各 63px（5%），
结果**头顶和靴底同时被削**。根因不是裁切参数，而是参考图 8073 本身就是紧贴画框的全身机——图生图把占幅也学走了。

修法：v2 prompt 增加构图锁
`Scale the figure to about 78% of the frame height ... at least 8% empty background at the TOP and at the BOTTOM edge ...
Both the top of the head and both feet must be FULLY visible ... Do NOT fill the frame edge-to-edge like the reference image; pull the camera back.`
四张重出后头脚完整、留白正确，`_pending` 已用 v2 覆盖。
