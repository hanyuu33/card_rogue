# art_src —— 出图素材归档（**全部**，含被弃用的）

## 规则（R167 起 · 用户口径）

- **AI 出图过程中的所有图片都要入库**，不只是最终采用的那几张：
  raw 输出、被弃用的候选、中间处理件、当时的验收拼图，**全部保留**。
- 工程侧只把**采用的那张**放进 `assets/ui/`（那才是运行时素材）；
  本目录存的是**过程档案** —— 用来回溯「当初弃了什么、为什么弃」，
  也避免再出现「想找上一版结果已经没了」的情况。
- ⚠️ **`art_src/.gdignore` 必须存在**：它让 Godot 完全忽略本目录 ——
  否则这些图会被导入（生成 `.import` / `.ctex`）甚至被打进发布包的 pck，白白撑大体积。
- **新增一轮出图后**：把 `D:\work\gen_raw` 里新增的文件按下面同样的口径拷进
  对应轮次目录，再提交入库（不要只提交采用的那张）。
