## 四个坑

1. **AI 爱自画黑边/画框**：三张 3:2 原图里有两张在底部塞了一个 1/5~1/3 高的
   纯色带（moon 纯黑、cave 纯灰、furnace 拱形黑框）。判据：逐行亮度均值突然
   掉到 15~50 且方差 <5。处理分两种 —— 死色带用「亮度渐变到 0.26」吃掉，
   有形状的框（拱形）用「取上方一条地面色向下拉伸 + 高斯模糊 + 压暗」拉平。
   **不要用镜像补带**：会把最亮的那一条复制下去，接缝一眼可见（第一版 moon 的错）。
2. **`TextureRect` 默认 `EXPAND_KEEP_SIZE` 又踩了一次**（R511 在占卜球上踩过）：
   EventPic 的框是 320×240，但 2× 素材（640×480）会把 size 顶回去 →
   图整体位移 + 溢出。必须 `EXPAND_IGNORE_SIZE`。
3. **`add_child` 是「加到最上层」**：EventPic 一加就盖住了文案与选项按钮
   （全黑矩形直接压字）。必须 `move_child(tr, 1)`，与缺图兜底同层。
   这两条在此之前从没暴露 —— 因为 `event_*.png` 一张都不存在，插图分支一直是死代码。
4. **小尺寸观感**：320×240 下细节会糊，凝视图先按实际尺寸看，再决定 gamma / 分层遮罩。
