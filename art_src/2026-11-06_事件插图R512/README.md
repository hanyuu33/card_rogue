## 发光体（event_gaze 第二版）

用户口径：**要有发光感，不需要清晰的细节；眼部以外也不该这么清楚。**

AI 直出的"发光眼"仍然会把虹膜纹理、反光点、眶骨画实 —— 提示词写再狠也只是概率。
结论：**发光类素材不靠 AI 出像素，靠程序化**。

做法（`tools/glow_gaze_发光重绘.py`）：
1. 亮度场 `I = exp(-k·r^p)`，r 是椭圆归一化半径 → 中心实、边缘指数衰减，天然没有硬边；
2. **亮度直接当温度**：`I→颜色` 查表（1.00 白热 → 0.60 琥珀 → 0.30 赤 → 0.03 熄），
   所以画面里没有任何"纹理"，只有温度层次；
3. 竖瞳用**梭形遮罩**（半宽 `w·sqrt(1-t²)`，上下收尖），不是矩形缝；
4. 低幅角度扰动（`0.075sin3θ + 0.042sin5.7θ`）打破完美圆；幅度再大就成花瓣毛刺；
5. 光渗：blur 7 / blur 22 两层 screen，**之后**再把瞳缝压回黑（先糊后压，
   否则 bloom 会把瞳孔染成灰条）；
6. 中心白热点的位置要**避开瞳缝**（偏到虹膜外侧），压在缝里会变成一根银条；
7. 左右眼给不同参数（半轴 / 上眼睑压暗 / 瞳倾角），绝对对称会像图标。

在浅色羊皮纸事件页上，插图不能是矩形黑块 —— 用**椭圆 alpha 暗场**（中心 302×230，
0.50→1.02 淡出，blur 16）让黑暗化进纸里。

## 四个坑

1. **AI 爱自画黑边/画框**：三张 3:2 原图里有两张在底部塞了一个 1/5~1/3 高的
   纯色带（moon 纯黑、cave 纯灰、furnace 拱形黑框）。判据：逐行亮度均值突然
   掉到 15~50 且方差 <5。处理分两种 —— 死色带用「亮度渐变到 0.26」吃掉，
   有形状的框（拱形）用「取上方一条地面色向下拉伸 + 高斯模糊 + 压暗」拉平。
   **不要用镜像补带**：会把最亮的那一条复制下去，接缝一眼可见（第一版 moon 的错）。
2. **`TextureRect` 默认 `EXPAND_KEEP_SIZE` 又踩了一次**（R511 在占卜球上踩过）：
   EventPic 的框是 320×240，但 2× 素材（640×480）会把 size 顶回去 →
   图整体位移 + 溢出。必须 `EXPAND_IGNORE_SIZE`。
3. **`add_child` 是「加到最上层」**：EventPic 一加就盖住了文案与选项按钮
   （全黑矩形直接压字）。必须 `move_child(tr, 1)`，与缺图兜底同层。
   这两条在此之前从没暴露 —— 因为 `event_*.png` 一张都不存在，插图分支一直是死代码。
4. **小尺寸观感**：320×240 下细节会糊，凝视图先按实际尺寸看，再决定 gamma / 分层遮罩。
