# R197 虚空洞口弹窗底（void_portal.png）

## 用途
战斗内「敌方效果」开场弹窗的背景素材：入场巡场动画播完后，若关卡带
`enemy_effects`，弹出窗口展示敌方效果。洞口中心强制纯黑，文字画白色。

## 规格与几何契约
- 成品 `assets/ui/void_portal.png` = **768×540**（与弹窗 1:1，不缩放）。
- **纯黑圆盘**：圆心 = 图几何中心 (384, 270)，半径 225（外缘 16px 羽化）。
- **代码侧文字区**：以同圆心为中心的 **336×252** 矩形（半宽 168 / 半高 126，
  角距 √(168²+126²) ≈ 210 < 225，四角都在纯黑内）。改布局时两边要一起改。

## 文件清单
- `raw_ai_portal.png` —— ImageGen 原图（1536×1024，未处理，含右下角水印）。
- `../tools/_process_void_portal.py` —— 处理脚本（去水印→裁切→缩放→强制纯黑→验收图）。
- `preview_text_region.png` —— 验收图：绿框 = 代码侧文字区 + 示例白字。

## 处理记录
- 采用第一张生成图：暗石圆环 + 紫/青电弧，构图居中、中心近黑。
- 水印处理：右下角「AI生成 WORKBUDDY」用左下角区域水平镜像覆盖。
- 中心纯黑：PIL 圆盘 r=225 + 羽化（实测 AI 环内半径 横 252 / 竖 225，未伤环）。

## 缺图回退
`UiAssets.void_portal()` 返回 null 时，battle_scene 回退程序化绘制：
深紫黑底 + 紫色圆环 + 纯黑内圆 —— 不空白、不报错。
