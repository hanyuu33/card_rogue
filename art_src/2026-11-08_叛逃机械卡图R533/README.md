## 二、俄式元素怎么落（不写成「苏联照片」）

- **涂装**：深橄榄绿（4BO 军绿）+ 褪色 + 冬季白浆擦痕 + 泥雪，金属是**粗糙铸钢**而非光面合金。
- **工艺感**：焊缝（bead weld）、成排铆钉、铸造麻面、掉漆露底、锈水痕。
- **轮廓**：方正、厚重、斜面多；避免圆润流线和赛博义体细线。
- **记号**：肩甲上一枚**单字希腊编号**（α / β / γ）被**红漆一道划掉** —— 这就是「编号作废」。
  红色五角星只作**喷涂图案**用，不许出现任何真实国旗 / 现代军种徽标。
- **不要**：义体人、机甲少女、光剑、霓虹蒸汽波、二战纪实摄影味。

## 三、出图规格（决定后期能不能一次过）

| 项 | 要求 |
|---|---|
| 尺寸 | 高 ≥ 1024；首选 **3:2 横构图**（1536×1024），1:1 也可以 |
| 安全区 | 最终要**居中裁成 448×403（1.112:1）**。1536×1024 时左右各裁掉 198px → **主体横向保持在中央 74% 内**；1:1 时上下各裁 5% → **头别贴顶、脚别贴底** |
| 画面 | 单人主体、居中、留一点背景纵深；**不要卡框、不要边框、不要 UI**、不要地面大字 |
| 文字 | 除肩甲那一个希腊字母外**不准有可读文字**；告示上的排版一律给「不可辨认的仿文字块」 |
| 水印 | 出图平台自带水印请留在右下角，裁切会带走；非右下角水印自己抹掉，别压主体 |
