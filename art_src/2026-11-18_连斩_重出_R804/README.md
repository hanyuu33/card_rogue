# R804 —— 连斩 9272 卡图重出（构图修正）

## 为什么重出

R803 那版被指出「构图不太符合逻辑」。复核后问题**出在 prompt 设定本身，不是模型画歪**：

| 现象 | 为什么逻辑不通 |
| --- | --- |
| 两把刀对称交叉成 X | 「连斩」是**同一柄刀连续斩击 X 次**；两把刀交叉读作双持 / 格挡封架 / 交叉斩，是另一种技能 |
| 交叉处刀身互相穿透 | 两把实体刀刃不可能互穿而无碰撞；视觉上像两根玻璃棒叠着，读者会找火花却找不到 |
| 完全左右对称 | 对称 = 静态装饰（剪刀、蝴蝶结），没有任何「连续」的时间信息 |
| 卡面可见带里两端刀柄均被切 | 448×404 的第 68..335 行才是实际显示区，刀柄正好掉在下缘外 |

## 新版的构图规则

一句话：**全图只允许出现一处刀柄 / 护手**，其余都是它的残影。

- 唯一护手固定在画面右下偏中，4 道刀身从它呈扇面辐射（每道差约 20°）；
- 最外侧那道最亮最实（最后挥出的一刀），越靠内越虚 → 透明度梯度直接编码了先后顺序；
- 四条刃光首尾相接，连成一条左下绕到右上、略微收拢的大弧线 = 全图「节奏线」；
- 这条约束同时消灭了三种误读：双持（只有一处刀柄）、对称装饰（扇面是单向的）、静态（弧线给出顺序）。
