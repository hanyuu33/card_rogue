## 逐张记录

### 8054 重启 —— 四稿

- **v1（纯文生图）**：赛璐璐上色成功，但**手变成横着握住按钮**，按钮没被按下去。废弃。
- **v2**：食指按下正确，但手指仍带真实皮肤纹理（指节褶皱、肉感光影）。废弃。
- **v3**：同上，手还是偏写实。废弃。
- **v4（采用）**：把手部描述改成**否定式清单**——
  `NO drawn knuckle creases, NO tendon lines, NO skin texture, NO pores, NO wrinkles, NO visible veins`，
  并写明「**只由三段圆润形体构成 + 一整块平涂肤色 + 一条硬边阴影**」、整只手其余部分出画失焦。
  一次到位。

> **教训**：写手不要只说「画一只动漫手」，要主动列「不画什么」。
> 只要「肉感 / 毛孔 / 油腻高光」任意一样出现，画面立刻从「画的」变「拍的」。

### 8036 维修间 —— 六稿

- **v1**：机器人四肢齐全，只算「拆开」。废弃。
- **v2**：球 + 圆环对应关系成立，但整体写实渲染、机体四肢齐。废弃。
- **v3（img2img）**：`REPAINT THE SAME PICTURE IN ANIME STYLE` + 逐条否定写实渲染，
  **输出与输入几乎一模一样**——画风被参照图锁死。废弃。
- **v4**：纯文生图但写「明亮工坊」，仍偏写实且过暗。废弃。
- **v5**：明亮了、关系也清楚，但仍是 3D 渲染质感。废弃。
- **v6（采用）**：`image1` = **8027**（机械之心角色正典卡图），`input_fidelity` = **low**，
  首句 `Use the reference image ONLY AS AN ART-STYLE REFERENCE: copy its drawing technique …`
  `Do NOT copy its scene, its characters, its composition. Paint a COMPLETELY DIFFERENT scene`。
  一次从 3D 渲染跳到干净动漫线稿。

> **教训一（适配）**：「零件和机体适配」不能靠文字说「匹配」，要写成**可数的同构**——
> **同直径 + 同孔数 + 同间距 + 同配色**，再加「零件正对接口下降」的方向关系。
> **教训二（画风）**：画风（3D 渲染 vs 动漫）与结构一样会被参照图锁死，img2img 救不回来；
> 换画风要用**风格参照**（另一张已定稿卡图 + `input_fidelity: low` + `ONLY AS AN ART-STYLE REFERENCE`）。

### 9076 魔力核心 —— 六稿

- **v1**：平视/仰视整棵树，淡黄平圆盘 + 月面斑点 → **读成月亮**。废弃。
- **v2**：琥珀感对了，但**光球变成多面体**，视角仍平视。废弃。
- **v3（关键突破）**：把「俯视」翻译成**「看见叶子正面（有光泽的上表面），不是背面、不是透光的叶脉」**——
  视角一次翻上去；同时树冠被四边裁掉、枝条向外放射。但球偏小。
- **v4**：img2img 放大到半幅，结果**太大太扁**，像一锅琥珀汤。废弃。
- **v5**：img2img 改「三分之一画幅 + 球面明暗」，尺寸与体积都对，但**没照亮周围叶子**，读不出「发光体」。废弃。
- **v6（采用）**：img2img 只改光——暖琥珀光溢出到近处叶片、叶尖转金、
  内部丝状光与气泡**绕球面弯曲**、左上高光 + 右下暗边、壳外飘几粒发光微尘。

> **教训一（俯视）**：写「high angle」没用，要写**「看见叶子正面而不是背面」**——
> 从下往上看必然透光，这条一写视角立刻翻上去。
> **教训二（像不像月亮）**：看三件事——**平不平**（有没有体积）、**黄不黄**（有没有琥珀的橙棕过渡）、
> **亮不亮别人**（有没有照亮周围）。三样都补上，圆的也不会读成月亮。
