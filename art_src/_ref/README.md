## 二、提炼：所谓「科技感」其实是五条做法

1. **底要干净**：纯色或极简渐变（纯白 / 象牙 / 冷灰 / 纯黑 / 单一撞色）。
   堆场景细节（烟雾、链条、废墟）只会让缩略图变糊——这正是我们前几版 8060 的问题。
2. **主体是全身或七分身站姿**，剪影清楚，脚不切边。
3. **点缀色只有一个，占 5%~10% 面积，且只出现在"技术物"上**
   （发射核心、全息面板、护目镜框、接缝）。皮肤、织物保持低饱和。
   —— 人物自己**不发光**，光是技术物打在她脸上的。
4. **线条对比即科技感**：头发/织物走细线柔软，机械/装置走硬边 + 三角高光。
   两种笔触并置，观众才读得出"人 + 造物"。
5. **不要靠发光证明身份**（R438 已经因此退过三版）：人形机器人就是人形，
   身份交给**她在做什么**去交代。

### 反例清单（踩过的）
- 满屏霓虹 + 荧光发色 → 缩到 110px 是彩噪
- 球形能量罩包住人物 → 人物被吃掉
- 身体全息粒子化 → 推翻"人形"设定
- 发光环瞳 / 护目镜 → 直接被用户驳回两次

## 四、机械之心返修规范（R440，返修 7 张后收敛）

### 背景：不是清空，是「有地方但让位」
早期我把「底要干净」执行成纯渐变 / 白底 —— 缩略图干净了，但整张卡像贴在墙上的设定稿。
正解：**背景是一处真实空间**（机库 / 整备间 / 机房 / 管线隧道），再用景深让它让位。

```
BACKGROUND: <场景> ... rendered with SHALLOW DEPTH OF FIELD: softly blurred,
lower contrast, cooler and darker than the subject, its cyan accents dimmed,
so it reads as a believable space without competing with the silhouette.
```
反面词固定：`NO empty blank backdrop, NO plain gradient background only,
NO white void, NO studio backdrop`。
参考：`scenebg` 01/03/05/06/08、`mecha` 05/07/04。

### 配色三件套
钢灰 / 哑光枪灰打底 ＋ **冷青发光缝线**（唯一强光）＋ **极小面积琥珀警示黄**
（只在角板、地贴、警报灯，5% 以内）。共同元素 = **湿反光金属地板 + 顶部灯带**，
这两样一有，科幻感立刻成立。

### 画风分工
装备 / 工事 / 机甲卡走**硬表面**（清晰线稿 + 平涂 + 一个强光源）；人物卡走**动漫赛璐璐**。
两者同职业并存不冲突，别互相套。

### ⚠️ 两条硬禁令
1. **一个活人都不许有** —— 固定反面词
   `Absolutely NO people, NO characters, NO hands, NO soldiers, NO human silhouettes`。
   技能 / 工事 / 场地卡不靠人叙事，靠「装置正在动作」：拨杆被推下、核心被装进胸口、
   电缆往地面拉弧。
2. **人形机体不许骷髅化 / 不许有脸** —— 头一律**闭合罩壳 + 传感器缝或单个镜头**。
   `NO skull, NO bone, NO teeth, NO jaw, NO eye sockets, NO ribcage, NO skeletal anatomy`，
   再加 `NO crawling pose, NO reaching pose`。瘫倒的机械要**侧躺 / 靠箱**，不是爬
   （「报废」第一版给了骷髅头 + 爬行姿势，读起来像尸骸，返工一次）。
