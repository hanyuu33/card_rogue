## 二、提炼：所谓「科技感」其实是五条做法

1. **底要干净**：纯色或极简渐变（纯白 / 象牙 / 冷灰 / 纯黑 / 单一撞色）。
   堆场景细节（烟雾、链条、废墟）只会让缩略图变糊——这正是我们前几版 8060 的问题。
2. **主体是全身或七分身站姿**，剪影清楚，脚不切边。
3. **点缀色只有一个，占 5%~10% 面积，且只出现在"技术物"上**
   （发射核心、全息面板、护目镜框、接缝）。皮肤、织物保持低饱和。
   —— 人物自己**不发光**，光是技术物打在她脸上的。
4. **线条对比即科技感**：头发/织物走细线柔软，机械/装置走硬边 + 三角高光。
   两种笔触并置，观众才读得出"人 + 造物"。
5. **不要靠发光证明身份**（R438 已经因此退过三版）：人形机器人就是人形，
   身份交给**她在做什么**去交代。

### 反例清单（踩过的）
- 满屏霓虹 + 荧光发色 → 缩到 110px 是彩噪
- 球形能量罩包住人物 → 人物被吃掉
- 身体全息粒子化 → 推翻"人形"设定
- 发光环瞳 / 护目镜 → 直接被用户驳回两次
