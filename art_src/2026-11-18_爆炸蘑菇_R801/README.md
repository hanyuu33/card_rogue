## 设计口径

「类似陷阱」= 放置型工具，所以图标要和已有的四件放置型（炸弹 / 冰冻 / 毒瓶 / 穿刺 / 河豚）

没有它，红伞盖蘑菇在 44px 下会被读成食物（和烤肉 7007 撞车），也体现不出「会炸」。
