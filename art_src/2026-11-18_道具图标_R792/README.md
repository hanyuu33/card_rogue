# R792 道具图标：板甲 / 兵 / 墙砖

128×128 无背景小图标，进 `assets/ui/relic_icon_<id>.png`（R577b 那条「每件道具都要有图标」的断言守着）。

## 口径

- 生成 → `raw/`（1024×1024，AI 生成，**背景常被画成棋盘格 = 伪透明**，右下角带水印）
- 抠图 + 缩 → `processed/` → 复制到 `assets/ui/`
- 抠图脚本：`tools/_make_r792_icons.py`（复用 `tools/_make_r755_icons.cut()`：四边泛洪取背景 →
  前景收 2px → 按 alpha bbox 居中留 7% 边 → LANCZOS 缩 128）

## 每张的前处理（脚本里已固化）

1. **抹水印**：`[0.86w, 0.93h] → 右下角` 整块涂白（水印固定贴在那里，主体不在这块）
2. 泛洪抠背景（判据「亮且不饱和」，棋盘格两色都满足）
3. 裁剪 + 缩放到 128
