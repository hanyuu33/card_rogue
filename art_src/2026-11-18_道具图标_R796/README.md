## 管线

1. 生成：内置图像生成，1024×1024，`background=transparent`，参考图 `assets/ui/relic_icon_6070.png`（板甲，R792）对齐风格。
   → `raw/<号>_<名>.png`
2. 抠图：`python tools/_make_r796_icons.py`
   - 生成图两个固定毛病：① 背景有时被画成**棋盘格**（伪透明）；② **右下角带水印**。
   - 水印先按 `[0.86w, 0.93h] → 右下` 涂白，再交给 `_make_r755_icons.cut()` 做四边泛洪抠图。
   - `import _make_r755_icons` 会重跑它顶层那两张旧图 → 脚本里 import 前后比 md5，变了就 `git checkout` 还原。
3. 导入：`godot --headless --path . --import`（必须有 `.import`，否则 `ResourceLoader.exists()` 类断言假红）。
4. 验收：`processed/_preview_44px.png`（128 / 44px 两排，44px 是道具栏与工具栏的真实尺寸）。

## 造型取舍

- **6076 兔脚**：金环 + 绒毛 + 深蓝描边。44px 下靠「圆头 + 金环」认。
- **6077 钻头**：六角基座 + 螺旋钻杆 + 黄铜箍，金属灰为主 → 与板甲 / 应急装甲那种「胸甲」轮廓分开。
- **7013 卡牌包**：牛皮纸袋 + 蝴蝶结 + 三张彩色卡露出袋口（一眼看出「里面是卡」）。
- **7014 智慧药剂**：**圆肚玻璃瓶 + 星点**。故意与 7006 法力药剂（窄瓶 + 蓝色菱形符文）拉开形状差 ——
  两瓶都蓝，44px 下靠「圆 vs 窄」和那颗星区分。
