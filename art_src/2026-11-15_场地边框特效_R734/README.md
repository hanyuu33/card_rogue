# R734 · 场地边框特效（委托 codex）

6 张「场地」kind 卡 + 火墙术 9084 的格子特效素材。**本轮只出素材，不动代码**（店长口径）。

## 一、为什么是「边框环」而不是「格子内摆个图标」

场地不是单位（不能被攻击、不占位），已有的表达是「斜纹底 + 右下角名字角标」（`_draw_field_markers`）。
再往格子中间放图标会跟站着的单位卡抢视觉。所以这批做成**绕格子一圈的元素能量带**：
只吃边缘，中间留空，单位卡踩上去照样一眼看清。

## 二、几何（数是从代码里量的，不是估的）

| 项 | 值 | 出处 |
|---|---|---|
| 格子 | 124 × 110 | `battle_scene.gd` `CELL_W` / `CELL` |
| 竖置战场卡 | 76.6 × 92.4 | `CARD_W/ CARD_H × BOARD_SCALE(1.2157)` |
| 卡居中后左右余量 | 23.7 px | (124 − 76.6) / 2 |
| 卡居中后上下余量 | 8.8 px | (110 − 92.4) / 2 |
| 横置卡余量 | 左右 15.8 / 上下 16.7 | (124 − 92.4) / 2、(110 − 76.6) / 2 |

⚠️ **竖置卡上下只剩 8.8 px** —— 如果环只能画在「卡外面」，带宽就被锁死在 8 px，做不出体积。
所以本批按店长 2026-11-15 的口径：**绘制层级压在单位卡之下**（`_draw_field_markers` 那一步在
`_draw_board_cards` 之前），环带可以做到 12~18 px，内侧被卡盖住的部分是「卡压着光」，不是穿帮。

## 三、素材规格

| 项 | 环（6 张场地） | 横条（火墙 9084） |
|---|---|---|
| 文件 | `assets/fx/fld_<id>.png` | `assets/fx/fld_firewall.png` |
| 尺寸 | 496 × 440（= 124×110 的 4 倍） | 1488 × 440（= 372×110 的 4 倍，一整行 3 格） |
| 格式 | PNG RGBA，纯黑底转直通 alpha | 同左 |
| 混合 | 加色（additive）；黑 = 不可见 | 同左 |
| 环带 | 约画面高 12~15%，四边连续、四角有装饰簇 | 火焰占下 60%，上 35% 渐隐到黑；两端开口 |

**为什么不是正方形素材**：正方形铺到 124×110 会横向压扁 12.7%（环带左右变窄、上下变厚）。
按真实比例出图，绘制时 `draw_texture_rect(tex, cell_rect)` 一行不差。

**为什么不平移 / trim + 等比 fit**：那是 R675 中心爆点的做法。环必须让**外沿贴住贴图四边**，
所以 `_finish_fx.normalize()` 走「alpha 外接框 → 精确拉伸」，不保留黑边。

## 四、接入要点（下一轮）

1. 环：在 `_draw_field_markers()` 里、画斜纹底之前，对每个 `field_effects` 格子
   `draw_texture_rect(fld_<id>, _cell_rect(cell), false, Color(1,1,1,alpha))`。
   顺序天然在卡下面（`_draw_grid` → `_draw_field_markers` → `_draw_board_cards`）。
2. 火墙：`_draw_grid()` 里现在那两行 `draw_rect`（底 + 描边）换成整行贴图，
   `Rect2(GRID_X, GRID_Y + row*CELL - _grid_scroll, GRID_W, CELL)`。
3. 缺图回退：沿用 `UiAssets.get_tex()` 拿不到就退回现在的程序化斜纹/描边，别硬崩。
4. 敌我区分仍靠 `modulate`（我方暖/敌方冷），**不要**为此再出一批图。

## 五、验收判据（`_review/r734_field_ring.html`）

- **卡面不被压住**：预演里卡的上沿、角标、文字都完整可见。
- **四边不断**：`_finish_fx.py` 量四边外侧 22% 带的 alpha 覆盖率，任一边 < 6% 就在验收页挂 ⚠。
- **中心不填满**：非透光率 > 45% 即视为环被画成了实心块。
