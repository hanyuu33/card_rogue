## 两次返工的原因（都会复发，写在这里）

**1. `cut()` 的 `bright=` 不是背景阈值。** 第一版给 6081~6084 都传了 `bright=190`，
成品全部变成纯白方块 —— 那个参数是「成品亮度增强」乘算，不是「什么亮度算背景」。
背景阈值只能走 `**bg_kw` 的默认值（生成图底子本来就是 254~255 的浅暖白，够用）。
**规则：抠图别动 `bright`。**

**2. 戒指的圈内空腔，四边泛洪永远吃不到。** 6082 的戒圈内部是**被前景包围**的白色，
边框泛洪走不进去 → 深色道具栏上留一块白饼。补了一步 `punch_hole()`：
从孔心 `(512,560)`（1024 原图坐标）对「白且不饱和」的像素泛洪 → 只挖与孔心连通的一片，
不会误伤金戒指本体和别处高光。

**3. 怀表链条出画。** 6084 第一版提环与链条向画布上缘跑出去，被裁掉一截。
重出时在提示词里改成可数的硬约束 —— `whole object fully visible inside the frame,
clear empty margin on all four sides`，第二版完整。
