# R498 卡图区窄边框（五类归属）

## 结论

卡图窗上加一圈**窄边框**，按卡牌归属换素材：森林精魄（藤蔓与绿叶）/ 暗影刺客（黑影）/
机械之心（齿轮）/ 公用（白框）/ 敌人（红框）。采用 **200 × 160 整张拉伸**（不是九宫格）。

- 素材：`assets/ui/art_frame_<forest|shadow|mech|common|enemy>.png`
- 生成脚本：`art_src/tools/_gen_art_frames.py`（**改设计改脚本重跑，别手改 PNG**）
- 代码：`UiAssets.art_frame()` + `CardFace.art_frame_kind()` / `_draw_art_frame()`

## 为什么是「程序生成」而不是 AI 出图

这类素材是**几何约束型**的：四边必须等宽、中心必须全透明、最外 1px 必须不透明、
画幅必须卡在 1.25。AI 出图没法保证这些（尤其是「中心透明」和「边缘闭合」），
生成后一律要人工重绘边角，反而更慢。程序生成可以一次定义、反复微调数值重跑。

## 采用 / 弃用

| 版本 | 结论 | 原因 |
|---|---|---|
| v1（主环 T=10、叶子 12×3.6、螺栓 r=9、尖刺 27） | **弃用** | 216×260 的卡上边宽偏粗、四角装饰太大（暗影的尖爪几乎连成一个 X、机械的齿像贴纸），与「窄一点」的诉求相反 |
| v2（主环 T=8、叶子 9×2.8、螺栓 r=7、尖刺 22；暗影雾色压暗） | **采用** | 边宽约占卡宽 4%，58×70 的战场小卡上仍能靠颜色分辨五类，216×260 上装饰不抢卡图 |

第一版的成品 PNG 已被 v2 覆盖（同文件名）。脚本里所有尺寸都是常量，要回看 v1 直接把
`T` / 叶子 `leaf_pts` 的三、四个数字改回去重跑即可。

## 设计硬要求（换图必须守住）

1. **中心全透明** —— 它是盖在卡图**之上**的，中心有任何底色都会遮住画面。
   脚本 `save()` 里有断言：`alpha(中心) == 0`。
2. **最外 1px 有颜色** —— 卡图是出血到卡边的（R165 开放式卡图），外缘留透明会在
   纸底上露一条缝。脚本同样有断言（上缘 / 左缘 alpha > 200）。
3. **画幅 1.25** —— 卡图窗宽高比 = `rect.w / (rect.h × CARD_ART_RATIO)`，各调用方
   实测 1.244~1.255。素材按这个比例画，拉伸几乎不变形，所以**不需要九宫格**；
   反过来若把素材画成正方形，纵向会被拉宽 25%。
4. **边框要薄** —— 主环 8px / 200 宽 = 4%。别做大块花纹，卡图是主角。

## 判定口径（`CardFace.art_frame_kind`）

```
敌人（group == "enemy"）        → enemy      ← 优先级最高：敌人卡也带 class，一律红框
card_class == 森林精魄/暗影刺客/机械之心 → forest / shadow / mech
其余（没有职业的公用卡）        → common
```

⚠️ 用 `card.card_class`（卡面原始职业），**不跟** `PlayerClass.skin_class()`：
公用初始卡跟着当前职业变色的话，「公用白框」这一档就永远看不见了。
