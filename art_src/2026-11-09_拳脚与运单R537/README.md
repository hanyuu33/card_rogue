# R537 · 通用拳脚 ×3 + 惊喜运单（9215 / 9216 / 9217 / 8079）

- 批次定性：**通用「基础拳脚」三连**（同为 通用 · 技能 · 普通 r5 · 2 费 · 红）+ **机械之心 稀有效果卡**一张。
- 缺口：这四张一张图都没有；三张拳脚是通用池里唯一还成组缺图的战斗卡。
- 用户口径（2026-11-09）：从缺图清单里点名 **B 组（拳脚三张）+ 8079 惊喜运单**。

## 一、为什么拳脚三张不画人

通用卡不属于任何职业，画了具体角色就会绑死一个职业（森林精魄 / 暗影刺客 / 机械之心 共用）。
现有通用卡已定下的惯例是**只画「物」不画人** —— 例：`9169 烈火之剑` 就是一把插在石板上的烧剑、
`9179 惊奇盒子` 是一只弹开的箱子。三张拳脚沿用这条：画**拳、脚、冲击**本身。

## 三、三条硬约束（踩过的坑）

1. **不许出现人**：不要脸、不要躯干、不要完整手臂；只允许「截到手腕/小臂」的前臂、或只有靴子。
2. **光只有一处**：三张都是红→橙单一强调色；禁霓虹爆闪、禁全屏发光、禁彩虹彩噪。
3. **不许有字**：无文字、无数字、无标志、无水印、无卡框。8079 箱上那块铭牌只能是「不可辨认的刻痕纹理」，
   唯一允许的符号是蜡封上压出来的那个**问号**（符号，不是字）。

## 四、出图规格

| 项 | 要求 |
|---|---|
| 尺寸 | 首选 **3:2 横构图 1536×1024**（1:1 也可） |
| 安全区 | 最终居中裁成 **448×403**。1536×1024 时左右各裁 ~198px → **主体横向放在中央 74% 内**；1:1 时上下各裁 5% |
| 画面 | 主体居中、留一点纵深；**不要卡框、不要边框、不要 UI、不要地面大字** |
| 水印 | 平台水印留在右下角（裁切会带走）；压到主体的水印自己抹掉 |

### 9215 v5：真正要改的只有「头」

v4 我把「不要 Q 版」理解成「画成年人」，画成 24 岁的成年武者，方向就偏了 ——
这个角色本来就是**细瘦少女**，该留的是少女感，该去的是**过大的头**。

| 版本 | 体型写法 | 结果 |
|---|---|---|
| v3 | 没写 | 3.7 头身，头占身高 1/3.8 |
| v4 | `SLIM YOUNG ADULT WOMAN / 七头身 / 24 岁` | 成年女性，成熟脸，**方向错了** |
| **v5** | `SLENDER TEENAGE GIRL / 十五岁 / 六头身 / **头宽 ≤ 身高 1/7** / 窄肩平胸无曲线`，禁 chibi・SD・大头，**同禁成年女性・成熟脸・肌肉臂・曲线** | 少女体型，头明显缩小 |

两条可以复用的写法：
- 把「要什么」和「不要什么」**分开列两段**：`BODY TYPE — THE ONE THING TO GET RIGHT`（要少女、头小）
  ＋ `The ONLY thing to avoid is the CHIBI BIG HEAD`（只禁大头）。只写「不要 Q 版」会被模型读成「画成熟点」。
- 负面清单**两边都要列**：既列 `chibi / SD / 大头 / 幼儿体型`，也列 `adult woman / mature face / curves /
  muscular arms`，否则去掉一头就滑到另一头。

### 8079 v7：两个物体必须分得开

v6 的问题不是「罐里画了什么」，而是**箱壁被玻璃取代**，箱子和罐子长成一件东西 ——
最后读起来就是一只鱼缸。参考图那件装置本身就像鱼缸，一旦与箱体融合，「惊喜运单」就成了「箱形鱼缸」。

v7 的写法是把画面拆成 `OBJECT 1 — THE CRATE` 与 `OBJECT 2 — THE JAR` 两节，并给三条**可验证的分离依据**：

1. 罐子**自带**铬底座 + 四只小脚，踩在稻草上（不是嵌在箱体里）；
2. 罐子**比箱口矮、比箱口窄**，四周都能看见箱沿；
3. 透过玻璃能看见**箱内的白色搪瓷内壁与稻草在罐子背后**，罐壁与箱壁之间有稻草间隙。

`the crate itself made of glass / the crate walls replaced by glass / an aquarium built into the box /
a single tall glass tank standing where the crate should be / the jar sitting flush with the crate rim`。
顺带禁掉一切鱼缸装饰（砂石 / 水草 / 珊瑚 / 沉船 / 气石），避免滑向家用鱼缸的图式。
