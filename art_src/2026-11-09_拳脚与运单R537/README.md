# R537 · 通用拳脚 ×3 + 惊喜运单（9215 / 9216 / 9217 / 8079）

- 批次定性：**通用「基础拳脚」三连**（同为 通用 · 技能 · 普通 r5 · 2 费 · 红）+ **机械之心 稀有效果卡**一张。
- 缺口：这四张一张图都没有；三张拳脚是通用池里唯一还成组缺图的战斗卡。
- 用户口径（2026-11-09）：从缺图清单里点名 **B 组（拳脚三张）+ 8079 惊喜运单**。

## 一、为什么拳脚三张不画人

通用卡不属于任何职业，画了具体角色就会绑死一个职业（森林精魄 / 暗影刺客 / 机械之心 共用）。
现有通用卡已定下的惯例是**只画「物」不画人** —— 例：`9169 烈火之剑` 就是一把插在石板上的烧剑、
`9179 惊奇盒子` 是一只弹开的箱子。三张拳脚沿用这条：画**拳、脚、冲击**本身。

构图语言刻意区分开，并排放在卡册里不会像三张同一张图。

## 三、三条硬约束（踩过的坑）

1. **不许出现人**：不要脸、不要躯干、不要完整手臂；只允许「截到手腕/小臂」的前臂、或只有靴子。
2. **光只有一处**：三张都是红→橙单一强调色；禁霓虹爆闪、禁全屏发光、禁彩虹彩噪。
3. **不许有字**：无文字、无数字、无标志、无水印、无卡框。8079 箱上那块铭牌只能是「不可辨认的刻痕纹理」，
   唯一允许的符号是蜡封上压出来的那个**问号**（符号，不是字）。

## 四、出图规格

| 项 | 要求 |
|---|---|
| 尺寸 | 首选 **3:2 横构图 1536×1024**（1:1 也可） |
| 安全区 | 最终居中裁成 **448×403**。1536×1024 时左右各裁 ~198px → **主体横向放在中央 74% 内**；1:1 时上下各裁 5% |
| 画面 | 主体居中、留一点纵深；**不要卡框、不要边框、不要 UI、不要地面大字** |
| 水印 | 平台水印留在右下角（裁切会带走）；压到主体的水印自己抹掉 |
