# R760 · 计量工坊三只单位卡图（codex 图生图）

## 需求

店长：R758 新增的二层普通困难「计量工坊」三只单位还没有卡图，按游戏画风生成，委托 codex。

`cards.json` 里 9260 / 9261 / 9262 的 `image` 都是空串 → 实机走程序化兜底。本批补图。

## 三只的设定（与卡面效果对齐）

| id | 名字 | 数值 | 造型落点 |
|---|---|---|---|
| 9260 | 常数测量员 | 0/1/1/60 | 精瘦的办事员：黄铜细肢 + 灰钢钟形躯干、单片青瞳、手持带游标与铅垂线的**竖立标尺** |
| 9261 | 精密计算者 | 6/1/2/60 | 敦实的算术机：三层黄铜**计算鼓**（刻线 + 青色指示缝）、侧面齿轮、**三只青瞳排成一行** + 黄铜号筒，双手扶一把竖向**计算尺** |
| 9262 | 负载增量员 | 4/1/1/60 | 弓背搬运工：厚铆接灰钢背、横条青色视镜、腰后黄黑警示条，背上**黄铜料斗装满空白卡**，正往髋部滑槽里推卡 |

三只共用一套设计语言（黄铜 + 冷灰钢 + 青色发光缝 + 一盏琥珀灯），这样它们和机械之心一族站在同一条线上，
同时彼此能一眼分开：**量具 / 算具 / 载具**。

## 画风

参考图 `assets/pics/_pending/8073.png`（聚能机兵，机械之心 · 本单位），`-i` 图生图，只借画法不抄内容：
日式动画赛璐璐上色、细而干净的黑色线稿、2～3 级硬边阴影、大块平涂、暗调虚化背景 + 明亮打光主体。

## 管线

```
python _run_codex.py            # v1 三张（约 3.5 分钟，一次过零重试）
python _finish.py               # 裁 448x404 落 assets/pics/_pending/ + 出验收页
python _run_codex.py --v2       # v2 三张（收紧构图）
python _finish.py --v2          # v2 只出对照图，不动 _pending
```

前置：代理必须可连（`http://127.0.0.1:7897`，需 clash-verge 起来，脚本先预检，不通就不开工）。

## 两版为什么要重来一次

v1 三张都**贴着画框**：9260 的标尺上下顶边、9262 的卡堆冲出上边、9261 干脆**没画出头**（三只透镜缺席）。
v2 每份 prompt 都重写了 COMPOSITION 段，明确「主体占画幅约 62～65%、四周留空、任何东西都不许碰边」，
并把缺的元素点名写进去（9261 的「THREE round glowing CYAN LENSES + brass horn」）。
v2 三张全部合规，定稿取 v2。

⚠️ 本批是**插画**，`_finish.py` 里没有 R759 那个 `clean_flat()`（那是纯色底标志图专用的，会把主体外的
画面全涂成底色）。补边用相邻行高斯模糊拉伸。
