### 教训（待并入 ART.md）
- **「扁平」和「精细」是两根反向的绳子**：只写 `FLAT / 2 tone / NO gradient`，模型会把造型一起压成卡通剪影；
  只写 `detailed / layered robe`，它又滑回厚涂写实。有效的写法是**同时**给出
  「`THREE FLAT TONES max` + `every boundary a HARD SHARP EDGE` + `NO gradient`」**和**
  「`LARGE flat colour panels` 拼出体积 + `thick black ink outlines`」—— 体积靠**色块切分**，不靠渐变。
- **人形施法者是写实重灾区**：`ragged robe / high collar / hollow cheeks / dark lips` 这类描述会直接触发西方奇幻插画风。
  改成「大色块拼袍 + 面罩式简化脸」，并减少布料细节词，才拉得回赛璐璐。
- **模型会自己加白边做「竖幅海报」**：v3/v4 都在左右留 200px 纯白，`NO white border` 单独写压不住。
  要写成 **`CANVAS RULE`：背景铺满方画布四边、figure 居中、`NO vertical strip / NO banner / NO poster with margins`**。
  交稿前用 PIL 量一次四角 + 左右纯白列（脚本见本轮），别等切完 448 才发现内容只剩一条。

## 8059 机器鸟返工（14:26 用户：「为什么要故意做的破旧？」）

**我的原意**：它的效果是「每次获得改造时抽一张卡」，所以想用「补过很多次的车」——青色裂纹 + 歪铆齿轮——来暗示「被反复改造」。

**为什么这是错的**（三条）：
1. **时序错了**：改造是玩家**之后**对它做的事。卡面画的是它刚进场那一刻，那时它还没被改造过。把「被改造的痕迹」画进初始卡面，等于把后续操作提前写进插画。
2. **撞形象**：破旧 + 补丁 + 露线，读起来就是 9152 废弃机器人那一类。9152 在库里已经有图，两者不该同脸。
3. **档次不对**：8059 是 1 费 R0 普通卡，和量产型一个档次，应该是干净、规整、能一眼看出「可被改装」的白纸，而不是已经改烂的旧货。

**v2 处置**：正面写 `IN PERFECT SHAPE — freshly assembled, clean and well kept`；反面点名 `NO cracks / NO dents / NO rust / NO chipped paint / NO mismatched or crooked parts / NO gear riveted on crookedly / NO damage / NO worn-out look`。保留「叼空白纸卷」（这个是**抽牌**的叙事，与改造经历无关，应留）。

> 📌 通用判据（待并入 ART.md）：**卡面只画「这张卡进入战场那一刻」的状态**。
> 由玩家后续操作产生的变化（改造 / 附魔 / 升级痕迹）不能提前画进插画；
> 自带字段（次元 / 接通 / 嘲讽 / 亡语）才可以在画面上给符号。

### 教训
- **`fills about N percent of the frame` 同样压不住体量**（同 R412 素体那次的「feet 百分比」）：
  想让工事显小，光写百分比没用，必须同时给**形状约束**（`WIDER THAN IT IS TALL` / `NO spire NO pyramid NO ziggurat`）
  和**环境参照**（背景砖块大小、远处地面）。百分比只能当辅助。
- **暗塔 + 暗背景 = 448 下读不出轮廓**：必须显式要求 `tower lighter than background, background lighter than pure black`，
  否则一张 1024 看着有氛围，缩成卡面就是黑方块。
