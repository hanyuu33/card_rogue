## 逐张落地

### 9089 回转 —— `image1 = assets/pics/8002_shadow.png`（锁角色）

机制是「抽 X 张牌，X = 本回合已使用卡牌数」，所以把**旋转的弧线**当选视觉主体：
斗篷被离心力甩成一整道大弧占满上半画面，匕首划出的银白弧形轨迹描出转完一圈的路径，
**弧内侧飘着三四张半透明卡牌虚影**——这就是「抽上来的牌」，不用画成实体道具。
脸部只留兜帽下的三分之四侧后，一眼「转身」。

### 9113 黑暗扩散 —— 同参照，`input_fidelity = medium`

用户给的构图很特别：**卡图顶部是腿，下面是影子**。所以相机贴地、略微上仰，画面被切成两半：
上半只有靴子 / 小腿 / 斗篷下摆（到大腿就被上边缘切掉，**没有脸没有上身没有武器**），
下三分之二全是地面，影从脚下像墨滴入水一样一圈圈向外扩到画面四边，
地面被染黑开裂、波峰崩出紫色细火星。

写提示词时补了一句 `USE THE REFERENCE IMAGE ONLY FOR THE COSTUME AND COLOURS …
Do NOT copy the pose, the rooftop, the moon, the weapon or the camera angle`——
因为这张构图和参照图完全不同，不写这句会被参照构图的姿势带跑。

### 9126 捕兽大师

用户说的是「**猎户**」，不是暗影刺客角色，所以没喂角色参照，只靠紫黑皮甲 / 兜帽 / 腰挂铁夹
来暗示职业归属。要点：**野兔吊在腰高、耳朵下垂、身体软塌**，一眼是死的；
地上埋着一个半开的夹式陷阱、身后一道木桩铁丝的捕兽线。
血只留一点暗红在毛皮上，不画喷溅。

### 8036 维修间 —— 三稿

- **v1**：机械臂抓零件对了，但那台机器人**四肢齐全**，只算「半拆」，不算「残缺」。
- **v2（img2img，fidelity high，`CHANGE ONLY THE UNIT ON THE CRADLE`）**：
  写了「左臂完全消失、右腿膝盖以下断掉、断腿丢在地上」，**四肢还是一根没少**。
- **v3（纯文生图重画）**：一次到位——肩窝是个空的黑洞、断掉的线缆垂出来、
  胸腔敞开露出内骨架、姿势瘫软伏在工位上。

> 又一次验证：**「删掉原图里已经完整的结构」img2img 拉不动**，哪怕写了 `Do NOT restore
> any missing limb`。跟 8057 那圈六孔是同一个坑。

### 8054 重启

用户要「关机按钮（凸出的方形按钮）的特写，和按它的手」。做成极端微距：
**厚实凸起的方形按钮从拉丝钢面板里长出来**，按钮本体是磨旧的暗红（红 = 关机语义），
边角掉漆露出裸钢；食指已经把它按进去一半，**按钮与座之间的缝隙透出一圈暖琥珀**
（还在带电的意思）；手腕处一小截米色针织袖口，把「机械之心角色的手」交待掉。
面板上刻意**不刻任何字和符号**（`NO text, NO labels, NO symbols`），免得缩到 448 变糊点。

### 9058 奥秘精通 —— `image1 = assets/pics/8002_forest.png`（锁角色）

森林精魄的正典在 `8002_forest` 里最全（Q 版、浅金长卷发过膝、黑猫耳、**单条**蓬松黑尾、
琥珀金眼、绿叶围裙 + 雏菊、赤脚），所以直接喂这张，`input_fidelity = high`。
构图：盘腿坐在苔石上，双手捧着摊开的羊皮卷低头读，猫耳前倾、眉头微皱；
卷面是**不可读的古文字与手绘符号**（`no legible letters`），绿色光丝从字里升起来缠到脸侧。
羊皮纸的暖黄是画面唯一亮点，其余全压进冷绿暗部。

### 9076 魔力核心

用户要「大树树冠中心，淡黄色的光球」。所以整张就是**树冠**：层叠的绿叶与扭曲枝条
围成一个圆顶，正中心嵌一颗柔和无硬高光的淡黄光球，像心脏一样被最粗的枝干托着；
球周围的叶子被逆光打成半透明、叶脉可见、边缘转金，几片被光吸得向上卷起；
下方是深冷的林下阴影与雾。**光球是画面里唯一亮的东西。**
