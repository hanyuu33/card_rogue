# 2026-11-05 神秘商店货架重做（R508）

## 本轮要解决的问题（用户报障原话）

1. 商店「神秘商店」四个字的框被卡牌挡住；
2. 生命条又挡住了卡牌；
3. 降低货架第一行的高度，降低 1-2、2-3 行的间距；
4. 重新生成货架素材，「不需要这种护栏」，以便商品更像是摆在货架上；
5. （补充）货架最好有**后挡板**。

上一轮只做了第 3 条的一半（行距 14 → 10、木板 30 → 26），并且把 `UiAssets.get_tex("shelf")`
顺手改成了 `"shelf_open"` —— 而 `shelf_open.png` 从来没有生成过，于是 `_draw_shelves()` 一路
走缺图回退，画出「深棕横条 + 两端 8px 竖撑」的程序化木板：**这正是用户说的"护栏"**。
第 1、2 条靠把 `_top_h()` 从 64 顶到 124 硬躲，代价是三行整体下压、第三行几乎贴到「离开商店」。

## 落地内容

### 布局（`scripts/shop_scene.gd::_row_rects()` / `_top_h()`）

| 项 | 改前（未提交半成品） | 改后 | 理由 |
|---|---|---|---|
| `_top_h()` 顶部标题带 | 124 | **100** | 124 是躲标题的临时值。标题框底 = 58，卡顶价签最高点 = 卡顶 − 12，稀有度缎带探出约 20 → 卡顶 100 时三者都在 58 以下留 ≥ 20px |
| 层板厚 `shelf_h` | 26 | **30** | = `shelf_board.png` 的原始高度，不再垂直缩放，板的高光/厚度不糊 |
| 行距 `gap_v` | 10 | **8** | 用户口径「降低 1-2、2-3 行的间距」 |
| 第二/三行高度 | 均分后 `clamp(…, 140)` 上限 | **只保下限、不设上限** | 140 上限让 1024×768（逻辑 1280×960）把三行挤在屏幕上半、底下空 120px。现在多出的竖向空间落在背板上，是「货架上层还空着」，不是死白 |
| 底部呼吸位 | 无 | **16** | 第三行层板与「离开商店」按钮之间留 20px（原来 4px） |

`_row_rects()` 每行返回 `row` / `shelf` / `back` 三块几何（唯一口）：
商品摆放区、层板、后挡板。绘制与命中都只从这里取值。

### 绘制顺序（`_draw()`）

```
背包背景 → 老板立绘 → 标题
→ _draw_shelf_backs()   后挡板（在商品后面）
→ _draw_row1/2/3()      三行商品
→ _draw_shelf_boards()  层板（压在商品底部）
→ _draw_buy_buttons()   安卓「购买 · N」按钮（骑在层板上）
```

层板放在商品**之后**，图标底部才会被板自然压住；购买按钮再叠在板之上（24 高，上下各露 3px 板边，
上一轮 26 高几乎把 30 高的层板整条盖掉，第一行只剩一排绿按钮）。

### 商品"摆"在架子上的表现

- `_goods_icon_box(rr)`：图标方框**唯一几何口**，绘制与悬浮详情定位共用
  （原来两处各算一份 84 vs 80、下压 6% vs 不下压，图标一改大详情板就会压住图标顶）。
- 方框整体下压 6%：图标素材四周自带透明边距，正对层板顶画会凭空悬空约 30px。
- 底部一枚扁椭圆落影（`draw_set_transform` 压扁 0.30），下半截被后画的层板盖掉。
- 图标尺寸随行高自适应 `clamp(行高 × 0.64, 84, 120)`：4:3 窗口商品格高 246，固定 84 会缩在角落。
- `UiAssets.shop_icon()` 的纹理边长 64 → **96**：实际画到 84~120px，64 是被放大在用，边缘发虚。
