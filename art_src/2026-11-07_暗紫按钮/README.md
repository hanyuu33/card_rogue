# 2026-11-07 暗紫按钮（R517）

事件页统一暗紫肤之后，按钮底色对了，但**风格丢了**：R516 是用 `_btn_box` 画的纯色小圆角矩形，
而原来那套按钮是 `adventure_shared/button_paper.png` —— **两端尖角 + 黄铜金线 + 纸面纹理 + 两侧四角星**。
所以这一批不是重新设计，是把同一套形状**换色**。

## 为什么不用 modulate_color

`StyleBoxTexture.modulate_color` 是乘法。素材由「暖白纸面（≈#f0e6da）+ 黄铜金线（≈#cbb392）」组成，
金线本来就比纸暗；一旦乘上暗紫系数：

| | 原色 | × (0.18, 0.14, 0.24) |
|---|---|---|
| 纸面 | (240, 230, 218) | (43, 32, 52) ✅ 暗紫 |
| 金线 | (203, 179, 146) | (37, 25, 35) ❌ 比底色还暗，金线消失 |

金线正是这个按钮的识别特征，乘色等于把风格再丢一次。

## 做法：按「暖度」分离纸面与金线，各自重映射

`R − B` 这个分量能把两者干净分开：纸面约 22，金线约 57。中间 25→50 做线性过渡，避免锯齿。

* 金线 → `#c9a96a`（黄铜），**保留原图明暗起伏**
* 纸面 → `#2b2135`（= `UiTheme.NIGHT_BTN`），同样保留明暗起伏（所以纸纹还在，只是压暗了）
* alpha 完全不动 —— 尖角轮廓与抗锯齿原样保留

产出四张，尺寸与源一致（400×92），交给 Godot 九宫格拉伸：

| 文件 | 用途 | 系数（纸 / 金） |
|---|---|---|
| `button_night.png` | 常态 | 1.00 / 1.00 |
| `button_night_hover.png` | 悬浮 | 1.30 / 1.18 |
| `button_night_pressed.png` | 按下 | 0.78 / 0.84 |
| `button_night_disabled.png` | 禁用 | 0.70 / 0.50 |

## 复现

```bash
python art_src/2026-11-07_暗紫按钮/tools/make_night_buttons.py
```

改目标色就改脚本顶部的 `PAPER` / `GOLD`；想跟 `UiTheme.NIGHT_BTN` 对齐的话两边一起改。
本机没有 numpy，脚本是纯 PIL 逐像素（36800 像素，毫秒级）。

## 九宫格边距

`UiTheme.night_button_style()` 用的是 **左右 46 / 上下 16**：

* 46 = 尖角 + 四角星的整体宽度，改小会把星星拉变形
* 16 = 金线边框的厚度余量，素材 92 高被按钮 46 高压扁时金线才不会糊

## 顺带修的另一个问题

同一页的按钮**不同高**。`UiTheme._fit_action_button` 原本按 `btn.size.y <= 44` 判 compact，
而 `scenes/event.tscn` 里四个按钮的 `custom_minimum_size.y` 是 46 / 42 / 38 / 38 ——
第一个走大档（字号 FS_SUBHEAD），其余走小档（FS_LABEL + 更小内距）。
现在 night 路径强制 `compact = false`，场景里四个按钮统一 46 高。
