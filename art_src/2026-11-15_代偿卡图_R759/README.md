# R759 · 9252「代偿」卡图（codex 纯文生图）

## 需求

店长：代偿需要生成卡图，**诅咒风格用简约的标志（类似交通标志那种）**，委托 codex 生成。

同族参照：`9154 破绽` / `9185 麻痹` 已经是「圆牌 + 粗黑外环 + 白内环 + 中央单一符号」的标志语言，
代偿按这套做；`9149 疲惫` / `9157 罐子` 是插画风，不跟。

## 符号选型

费用在游戏里的象形是**蓝宝石**（`assets/ui/icon_cost.png`），所以符号用「宝石」而不是硬币——
代偿的效果是「这张卡在手卡时，其他手卡费用 +1」，画宝石最能一眼读出「费用」。

两个方案（都是纯 2D 矢量、3～4 个平涂色、粗黑描边）：

| 方案 | 构成 | 语义 |
|---|---|---|
| v1 重压 | 竖立宝石（六边尖底）+ 上方压一块厚重梯形配重 | 负担压在费用上 |
| v2 加价 | 宝石 + 两道等宽粗杠交叉成十字压在中央（宝石只露四块） | 费用 +1 |

调色走 `color: 暗影`：深靛紫外底、品红宝石、浅淡紫白高光、黑描边。

## 这轮踩到的两个坑（写进 `_finish.py` 里了）

1. **首版构图 70% 高 → 圆环被 1.51:1 横带切断**，补边时把 1px 行里的白环拉成两根白柱。
   改 prompt 把圆环缩到 58% 高（实际出图约 66%，仍在横带内、切边量与 `破绽`/`麻痹` 一致）。
2. **出图在背景上留了一道很淡的竖直暗纹**（`(13,1,38)` vs 背景 `(21,1,64)`），拉伸补边后变成一条黑带。
   修法不是调 prompt，而是收尾时 `clean_flat()`：四角取背景色 → 量出圆牌圆心/半径 → 圆牌以外全涂回背景色。
   顺带把补边接缝一起抹干净。
