## 遵守的既有纪律

- **规范 A**：非盟友／工事卡一律只画物件／特效，不凭空捏造人形、兜帽人、奔跑剪影。
- **规范 B**：除 9168 许愿（效果本身是拿卡）外，全批禁止卡牌元素。
- **纪律 E**：7 张全身主体（9028 / 9029 / 9048 / 9242 / 9243 / 9244 / 9245）写死 76% 占幅＋上下各 8% 留白＋头脚完整＋拉远镜头。
- **纪律 F**：验收看裁好的 448×403 总览，不只看 raw。
- **纪律 G**：留白不足用画布延展兜底，不改裁窗。
- **纪律 H**：写 prompt 前先读 `effect_text`；天线／碟／炮口等机械件默认不自发光，本批炮类全部画成「蓄能待机」而非发射光束。
