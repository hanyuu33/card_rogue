# R785 · 免伤力场素材（赫尔墨斯 9140 / 量产型赫尔墨斯 9188）

店长口径：「这个不好看，委托 codex 生成素材来做。」

R780b 那版是**程序化画的六边形金线**（双圈 + 顶点方块）。它在亮青色水面上要
「深底 + 亮金」双描才立得住，结果就是两根粗金线把卡牌箍住 —— 读起来像「卡牌边框
加粗」，而不像「多了个力场」。本批改成 codex 纯文生图的**发光结界素材**。

## 三版候选（`prompts/cap_aura_0N.txt`）

| 版本 | 形态 | 特点 |
|---|---|---|
| 01 | 金色六角晶格结界 | 细密晶格 + 交汇点亮斑，与卡牌金框同色系 |
| 02 | 琥珀符文结界 | 符文环 + 四向星标 + 环外光尘，最亮最显眼 |
| 03 | 白金色棱镜力场 | 六边形晶面 + 冰蓝折射，冷硬；但**和青色水面同色系，实战辨识度最低** |

切版只改 `battle_scene.gd` 的 `const CAP_AURA_VARIANT := 1`。

## 两套成品，实战用的是第二套

`_finish_fx.py` 每条 raw 出两张：

1. `fx_cap_aura_0N.png` —— **圆环版**（原样，只做黑底转 alpha）。留作对照与素材归档。
2. `fx_cap_aura_0N_card.png` —— **贴卡框版**，引擎实际加载的是这张。

### 为什么圆环不直接用（R785 首版实拍）

- 环外径必须 ≥ 卡牌对角线（76.6×92.4 → **120.0**），而格子宽只有 **124** →
  相邻两个满额度单位的光环会互相咬在一起；
- 环与卡边之间还留一圈空气 → 读起来是「卡牌漂在一个呼啦圈里」，不是「被罩住」。

### 贴卡框怎么做的：极坐标剖面 + 矩形距离场重映射

`profile()` 先量出 AI 圆环在 720 个角度上的**内缘 / 外缘半径**；
`remap_card()` 再对目标画布每个像素算「到卡牌矩形的带距离 t」，按
`r = rin(θ) + t·(rout(θ) - rin(θ))` 回采样源图 —— 等于把那道圆环沿卡牌轮廓抻成圆角矩形框。

**切向坐标必须用「沿矩形周长的位置 s」，不能用「方向角 θ」**：
R785 第二版用 θ，一条边上所有像素的 θ 几乎相同，全都从源图同一条射线取样，
纹理被抹成横条纹 / 纯色块（`_review/r785_card_frames.png` 第一版就是这个翻车样）。

## 三个像素口径，两处必须同源

| 常量 | 值（屏幕像素） | 含义 |
|---|---|---|
| `CAP_AURA_GAP` | 3.0 | 环带内缘与卡边的**空气**。贴着压上去会被读成「边框加粗」 |
| `CAP_AURA_BAND` | 11.5 | 环带厚度 |
| `CAP_AURA_PAD_PX` | 6.0 | 环带外留白（外发光 / 呼吸缩放不被切） |

素材画布 = 卡宽高各加 `2×(GAP+BAND+PAD)` = 4x 的 **470×534**，
`battle_scene._draw_damage_cap_aura()` 按 `w + (GAP+BAND+PAD)*2` 绘制 —— 改一边必须同改另一边。

总宽 = 76.5 + 2×20.5 = **117.5 < 格宽 124**（相邻不咬）；
总高 = 92.5 + 41 = **133.5 > 格高 110**（上下相邻行会各溢出 ~12px 柔光，属已知取舍：
把 band 收进 8px 才能不溢出，但那样素材就只剩一根细线）。

## alpha 曲线

口径同 R628：`alpha = 亮度^0.85`。
**别把光晕收紧**（试过 gain 1.18 + gamma 1.10）：素材缩到 11.5px 环带后只剩一根细线，
实战里被水面背景吃掉，读不出「罩住」（R785 第三版实拍）。

## 委托 codex 的两个坑

1. **必须清掉 WorkBuddy 注入的 `http_proxy=127.0.0.1:59266`**（白名单代理，访问
   chatgpt.com 一律超时）。用 Clash 的 **7897**，并先做代理预检。不清的话现象是
   「codex 静默卡十几分钟、一个字不吐」。
2. **prompt 走 stdin**、`-c model_reasoning_effort=low`；一次 exec 里连出 3 张，
   每张约 2~4 分钟（`_run_codex.py` 已按此实现，带重试与增量进度）。
