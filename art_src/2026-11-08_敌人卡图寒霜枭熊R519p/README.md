## 教训

- 水印区**上方是亮主体**（冰晶）时，用「上方镜像」`patch_wm` 会贴回亮色、被误判成残留；
  改用「左侧暗色地面水平镜像」`patch_from_left`。
- 半透明水印文字极淡（每行仅 4–7 白灰像素），客观检测「密集文字行（连续≥8）」才能可靠判断
  是否清除，不要只信单次视觉模型的「淡痕」判定。
