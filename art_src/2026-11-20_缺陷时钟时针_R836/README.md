## 为什么要「无指针」

指针要在动画里连续旋转一整圈 + 末段卡顿抖动。贴图旋转会有像素偏移与描边锯齿，
角度也没法和刻度精确对齐 —— 所以指针由 `battle_scene._draw_clock_fx()` 用
`draw_line` + 菱形针尖实时画，只让 codex 出盘面。

## 两个会复发的坑

**1. 表盘是米白，不能按亮度抠。** 盘面 `#EFE6D2` 与白底只差一点亮度，按亮度算 alpha
会把整个盘面吃掉。必须走 R755 的 `_bg_mask`（从四边泛洪「亮且不饱和」的连通区）——
盘面被深褐描边围住，从边界走不进去，天然安全。

**2. 轴座不在纹理几何中心。** 程序测质心：轴座在 (262, 265)，纹理中心 (256, 256)，
偏 **(+6, +9)**（512 空间）。不补这一步，指针会与轴座差 3~4px，静止帧一眼看出来。
绘制时按 `CLOCK_FACE_PIVOT = Vector2(6, 9) / 512` 反向平移整张表盘。
