## 教训（待并入 ART.md）

1. **「不做某动作」挡不住模型换一个相似物**。9175 写 `wooden grave marker without any carving`
   → 出来就是十字架；写成 **`SHAPE LOCK`：plain straight wooden POST + tied leaf bundle，
   点名 `NO cross / NO crucifix / NO religious symbol`** 才压住。
   同 1011：只写「塔盾占半幅」它给一块灰板，必须把**轮廓特征**逐条列出
   （圆角顶 / 收尖 / 包边 / 中央脊 / 抓握的手），而不是只给名字。
2. **单色金属要留一道对比**。1011 整张都是灰，448 下靠背景砖墙的明度差才立住；
   若背景也偏深就又是一块黑方块（同 R415 鲜血堡垒的坑）。
3. **道具型主体要「有一个人的手」**。1011 v2 加「手套抓盾内侧」之后，盾才被读成
   「被举着的盾」而不是「立在那里的板」。8078 若也要返工，同理该加一只扳手手 / 接线的手。
4. ⚠️ **8078 自评存疑**：现在的「半开盖板 + 玻璃管核心」在 448 下略像**提灯**。
   若用户判返工，方向是「工业接线的储能仓」——加粗电缆、拧在壳体上的法兰、
   边缘压出橡胶垫，去掉像灯罩的整圈玻璃。
