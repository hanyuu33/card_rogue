## 关键处理

### 1. 水印（这次是硬钉在画面里的）

后端默认水印「AI生成 WORKBUDDY」**固定像素尺寸贴右下角**（约 130×44，距右 6px、距底 12px）。

- **不能靠切边**：1300px 级的大图裁 16:9 时水印有时会被裁掉（1536×1024 → 裁 y 80~944，
  水印在 y 970 之外，自然消失），但 4:3 的插图裁不掉。
- **不能用绝对亮度检测**：水印是半透明压在原画上的，暗部只有 ~160 的亮度
  （1536 宽的 CG 完全检不到），亮部又会和画面里的白高光混（湖面花瓣是 255）。
  所以直接给**固定框**，别检测。
- 修补：取水印正上方一条等高画面 → 垂直镜像 → `GaussianBlur(2.0)` → 用软边遮罩
  （白矩形 + blur 3.2）羽化贴回。背景都是土路 / 苔藓 / 水面这类低结构纹理，
  肉眼看不出来；结构感强的画面（建筑边缘、直线）不能这么补。

### 2. 整屏 CG 的构图约束

`EventBG` 是 `STRETCH_KEEP_ASPECT_COVERED` 铺满 + 压到最底层（`move_child(trb, 0)`），
不会盖住正文。但正文卡片大概从画面 **y ≈ 45%** 开始，所以：

> **关键物件全部放在上半部与左右两侧，下三分之一刻意留空、压暗。**

两张 CG 的提示词都写死了这一条，实测 delivery 的货台完整露在卡片上方、
arcane 的护符与光柱正好落在卡片顶边之上。

### 3. 插图与背景不能同时给

插图（`event_*.png`）先加、在层 1；背景（`bg_*.png`）后加、压到层 0。
两者同时存在时，320×240 的插图会直接叠在 CG 上重复表达。

→ R515b 把 `assets/ui/event_delivery.png` 与 `event_arcane.png`（含 `.import`）**删掉**，
只留 `bg_*`。判据已写进 `UI设计规范.md`：**要"站进去"的走 bg_，只要一个符号性画面的走 event_**。
