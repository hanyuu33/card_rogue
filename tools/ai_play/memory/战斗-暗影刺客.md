# 战斗策略 · 暗影刺客

> **只读这一份就能打这一职业的战斗。** 不依赖「局外」那份；两份可以分别单独加载。
> 版本 v1（2026-10-27 建立）· 来源：卡面数据 + 首轮实战前推演。实战后按末尾「修正记录」改。

## 0. 这个职业的胜负手

暗影刺客**不是靠大怪站场赢的**，是靠「一回合内连打很多张 0 费/1 费技能，把伤害叠出来」。
初始卡组里 `攻击` 只有 4 点伤害，`幽影` 3/8 是个普通身材 —— 真正的爆发全在
**0 费技能链**上。所以三条铁律：

1. **0 费技能是主炮，不是补刀。** 每张都要算进「本回合已用卡数」。
2. **费用不能累积，所以「剩余费用」是有价的。** 回合末还剩 2~3 点不是浪费，
   是喂给 `地狱猫/鲜血堡垒/夜蚀/黑暗扩散/暗影之刃/活力转移` 的。
3. **每回合都要问一句「我这回合能打几张牌」。** 打得少 = 这回合白给。

## 1. 初始 13 张（认清它们分别干什么）

| 卡 | 费 | 定位 |
|---|---|---|
| 攻击 ×5 | 1 | 基础伤害 4。**优先当「凑卡数」的第 1~2 张**，别当主伤 |
| 木栅栏 ×5 | 2 | 0/6 工事，不能动。**堵路/挡刀/喂终结的计数**，不是战力 |
| 幽影 ×2 | 3 | 3/8 射1 移1。唯一能上前线打人的单位 |
| 终结 ×1 | 0 | **2+X**（X=本回合已用卡数）。全场最高收益的收尾牌 |

**终结的算法**：本回合先打 4 张再打终结 = 2+4 = **6 伤害，0 费**。
打 6 张 = 8 伤害。所以它是「最后一手」，永远最后按。

## 2. 每回合的固定检查清单

按顺序问自己，别跳步：

1. **我方有没有单位要动？** 有 `幽影` 在场 → 先看能不能攻击到人（射 1 = 曼哈顿 1 内）。
   能打就打 —— 攻击不花钱，是本回合的「免费伤害」。
2. **这回合要不要铺场？** 只有 3 费以上剩余、且对面有压力时才放 `幽影`。
   前 2 回合铺 1 个够用；铺 2 个会挤掉技能链的费用。
3. **0 费技能有几张？** 全打（它们不花钱）。
4. **1 费技能怎么排？** 先打「能加卡数/抽牌」的（`起手式` `连刺` `影袭`），
   再打纯伤害的（`攻击` `收尾`）。
5. **`终结` 放最后。** 如果手里有它，前面每多打一张它就 +1 伤害。
6. **留不留费？** 手上有 `地狱猫/鲜血堡垒/夜蚀/黑暗扩散/暗影之刃/活力转移`
   且这些已经在场上/效果区 → **刻意留 2~3 费**给它们结算，别再花光。
7. **结束回合前看一眼敌方下回合能打到谁。** 血少的单位往后撤或让木栅栏挡。

## 3. 出牌优先级（同费时的取舍）

```
免费抽牌/加卡数  >  0 费伤害  >  低费伤害  >  铺场  >  纯防守（木栅栏）
```

反例（新手最容易犯）：第一回合把 5 费全砸在 2 个 `幽影` + 1 个 `木栅栏` 上，
然后 0 费技能一张没打 —— 这回合等于只出了 3 张牌，`终结` 只有 2+X=2 点。

## 4. 站位与移动

- 棋盘 6 行 × 3 列。我方在第 3~5 行（第 3 行是前排，第 5 行是后排）。
- **射程 1 的 `幽影` 想打人必须站到第 2 行** —— 但那也在敌人射程内。换血要算清。
- **永远不能进对方后排**（第 0~2 行里对方后排是第 0 行…… 规则：任何方式都不能把单位放进对方后排）。
- `木栅栏` 放**第 3 行**（我方最前）：它的作用是让敌人多花一回合破它，
  同时它自己也会被 `终结` 的计数 …不行，它是单位不是牌。**木栅栏的真实价值 = 挡一刀 + 占格子**。

## 5. 打特定敌人

| 敌人特征 | 应对 |
|---|---|
| 高攻单体（骑士/队长） | 木栅栏顶前排，`幽影` 站后排射程外 |
| 远程弓手（射 2） | 别把单位放它正前方两格内；先手打死它 |
| 嘲讽单位 | 技能可以直接打它（技能不看嘲讽），用它当靶子刷「已用卡数」 |
| 会塞诅咒的（俄倪厄·破绽） | 尽快结束战斗，拖久牌库会全是废牌 |
| Boss（血量 100+） | 只有「每回合稳定打出 5+ 张牌」的节奏才打得穿，别打消耗战 |

## 6. 什么时候该 SL（rewind）

战斗 SL = `python ai_cli.py rewind`，回到本场刚开打那一刻（血、牌、随机源全部还原）。

**判定标准**（满足任一条就重开，别硬撑）：
- 打到第 2 回合结束，**我方掉血 > 最大生命的 40%**，且敌方场面没有被我方压制。
- 手牌打空、牌库也快空，而对面的主力单位还满血。
- 已经确定这回合会死（我方 HP ≤ 对面场攻合计）。
- **赢了但掉血 > 60%**（赢下来的收益不够赔的血，重开通常更划算）。

反过来**不要**因为「这回合打得不漂亮」就重开 —— SL 也有代价（时间），
只用来救「明显打不过 / 掉血过界」的局。
