# 局外策略 · 机械之心

> **只读这一份就能做这一职业的全部局外决策。** 不依赖另一份。>
> **边界（写死）：本文件承载「离开战斗之后」的一切** —— 选卡、删卡、商店、附魔、
> 篝火、事件、奖励领取、路线、道具取舍。战斗内的操作与数值一律不写在这里。
> 版本 v2（2026-10-30）· 依据种子 `NNIZFPJ2LI` / `4PX0IX36DL` / `ZCVOQYYACI` / `ASRJWVB3FC` 四局 + `ZDB7OWVKE9`（打到第 2 层 n8 全灭）实战。

## 0. 默认口径

- **道具：能不放弃就不放弃**；但 `洞窟绳`（非 Boss 战可逃跑）是**T0，必须拿**。
- **商店购买顺序：删卡 → 补乘法件 → 附魔 → 其他。**
- 初始 13 张是 `攻击×5 + 木栅栏×5 + 构装体×2 + 升级×1`，**没有 0 费**。
  `素体` 靠 `机械核心` 与奖励来，是**层数载体**，**不能删**。
  → 删卡顺序：**多余的 `木栅栏`（先删到 2~3 张）→ 多余的 `攻击`（留 3 张）**。

## 1. 进层第一件事：读图，不是先点最上面的房间（v1 新增，最重要）

四局全灭的共同原因不是操作，是**没看地图就直接沿一条线冲**。
每层开局 `state` 会给出三段信息，必须全部读完再动：

1. `未走的房间（可规划路线用）` —— 房间 id + 类型（战斗/精英/商店/宝箱/事件/休息）
2. `连线（未走房间 + 当前房）` —— 邻接关系，这才是地图的真形状
3. `当前房间` 与 `巧克力`（每层 12，每走一格 -1）

### 读数三步法

1. **圈出所有「精英」**（一层 = 3 个精英简单 + 3 个精英困难，共 6 个）。它们是**墙**，不是目标。
2. **找出不穿墙的连通块**：沿着连线走，把不经过精英能到达的房间全部列出来。
3. **在连通块里排一条链**，优先级
   `商店 > 宝箱 > 事件 > 休息（血<60%）> 普通战斗`，步数 ≤ 巧克力余量。

### 实测实例（种子 `Z8CEIR2FOF`，一层 35 格 / 12 巧克力）

- 精英在 **n4 / n9 / n12 / n13 / n14 / n16**（n12-n13 还是一对相邻双精英，等于墙上的墙）。
- **不穿墙可达 18 格**：n31(起点) n30 n32 n23 n24 n25 n26(休息) n33 n34(商店)
  n17(商店) n18 n11 n10(事件) n3(事件) n2 n19 n20 n27。
- **锁在墙后的高价值点**：n0(大宝箱) 必须过 n9/n16；n6(商店)、n29(宝箱)、n28(休息)
  必须过 n4/n12/n13 或 n14/n16。
- → 正确打法：**先把 18 格里那条「n31→n30→n23→n24→n17(商店)→n18→n11→n10(事件)→n3(事件)」
  或「n31→n32→n25→n26(休息)→n33→n34(商店)」走干**，攒出乘法件，**再**考虑穿墙拿大宝箱。

> 结论：**机械之心一层完全可以一个精英都不打**。走满非精英链 = 2 商店 + 1~2 事件 + 1 休息 +
> 5~6 场普通战斗，足够养出侦察塔/激发/共享护盾。

## 2. 打精英前的资源盘点（v1 新增，硬判据）

**四件里少于三件，就不打精英，改走绕行路线。**

| 检查项 | 打精英的门槛 |
|---|---|
| 乘法件 | `侦察塔` + `共享护盾` + `集中突破` 至少 2 件；一件都没有 = 不打 |
| 每回合输出 | 场上单位攻击总和 ≥ 15（初始卡组只有 ~10） |
| 血量 | ≥ 70%（46/66）；低于 40% 直奔篝火，别想精英 |
| 逃生手段 | `洞窟绳` 在手，或已确认绕行路线存在 |

算不平就用 `flee` 走人 —— **逃跑不扣奖励进度，只是白走一格**，比掉 40 血划算。

## 3. 开局三件起始道具（v1 按实战改）

优先级：

1. **`洞窟绳`（非 Boss 战可逃跑）** —— 前期打不过精英时唯一的安全阀，**遇到必拿**
2. **`栅栏修复术`（栅栏叠合 0/6+0/6=0/9）** —— 直接加厚工事宿主，与 `升级` 乘法叠加
3. **`鸭之低语`（每回合随机费 +1 / 伤害 +1 / 多抽 1）** —— 运气好直接加速整局
4. 加最大生命（`类固醇` +10）
5. 纯金币（`行囊` +100 金 = 一次删卡或一张卡）

避免：只加成「技能伤害」的（这个职业靠单位）、需要「打很多技能」才生效的。

## 4. 三选一选卡优先级（v1 全部按实战重排）

1. **`侦察塔`** —— 每层改造让射程内敌人受伤 +1，改造流的伤害乘数。见到就锁
2. **`共享护盾`** —— 挂在工事上能把「7 点血」拖满一整场（实测）
3. **`集中突破`** —— 10 + 层数 ×4，实测 46 点；一发定胜负
4. **`批量传输` / `激发`** —— 层数 + 补牌 / 改造即输出
5. **`升级` / `加厚装甲`** —— 层数发动机，永远不嫌多
6. **宿主**（`构装体` / `素体` / 带改造奖励的单位）
7. 其他

**不拿**：纯伤害技能（除非 0 费或多段）、「需要很多小怪」的卡。
⚠️ v0 写的「改造牌一律最高优先」**是错的** —— 只有改造牌没有乘法件时，
输出仍是线性 +2，一层精英照样追不上（四局实证）。

## 5. 商店

1. **删卡** —— 先删 `木栅栏`
2. **买乘法件**（侦察塔 / 共享护盾 / 集中突破 / 批量传输 / 激发）
3. 附魔 —— 给宿主单位（构装体）附「生命 +」或「力量 +」
4. 升级最大生命 / 巧克力

## 6. 事件取舍

- 先拿好处，没好处才离开。
- 「删一张卡」→ 删 `木栅栏`。
- 「改造一张卡」→ **对机械之心是正收益**（白给一层）。
- 「复制一张卡」→ 复制 `升级` 或 `侦察塔`。
- 「给随机道具」→ 优先（可能抽到洞窟绳/乘法件）。
- 代价是最大生命：血 > 60% 可以吃。

## 7. 血量与巧克力

- 66 血，中间档。**没有乘法件之前不要碰精英**，那段最脆弱。
- 血 < 40% 直奔篝火（休息回 40%）。
- **巧克力是路线预算**：每层 12 格，把步数算清楚再走；走进死胡同 = 白扔一个房间。

## 8. 卡组厚度

- 目标 **18~22 张**。四局里第 4 局卡组涨到 20 张、道具 5 件，是一层走得最远的一局。
- 但**单纯变厚不算变强**：奖励页优先拿乘法件，其次才是删卡，最后才随便拿牌。
- 同名牌超过 2 张基本是浪费（`攻击` 除外，前期靠它撑输出）。

## 10. 巧克力口径 + 第 2 层路线复盘（v2 新增）

**巧克力（已核对源码 `RunState.advance`）**：

- 每层初始 = 12（难度 8 起 11）；第 2 层实测进场是 **9**，所以要看 `state` 的实数，别背常数。
- **走没走过的房间 -1；走回头路 0 消耗、不结算**（`path_to` 只允许穿已走过的房间）。
  → 路线可以「一去一回」，回程不吃预算，死胡同房（只有一条连线的）也能顺手吃掉。
- 扣到 0 → 置 `boss_pending`，**当前房间要先结算完**，回到地图才「入夜」打本层 Boss。
- **第 3 层不收步数**（`free_layer`），Boss 由「走到直道尽头的 Boss 格」触发。

**这一局的路线（能抄的部分）**：

- 一条链吃满价值：`宝箱 → 战斗 → 休息 → 精英 → 精英 → 大宝箱 → 精英 → 战斗`。
  **休息插在精英之前**，把 34 血抬到 45 再进精英 —— 这个顺序是对的。
- 拿到 `鹿首标本` 之后，普通战斗变成「拖到第 5 回合一发清场」，掉血反而更少。
  → **技能流道具（每回合技能 +N）优先级高于单位流道具**。

**奖励 / 宝箱顺位（第 2 层工厂线实测）**：
`批量传输`(8040) > `量产型谟涅摩叙涅`(8075) > `集束炮台` > `改装者`(8076) > 宿主。
理由见战斗策略 §11「炮击引擎」—— 这三个 + `鹿首标本` 才是第 2 层的输出。

## 11. 第 2 层精英取舍（v2 新增，硬判据）

精英仍是唯一的高质量补强来源（v1 已证伪「全程躲精英」），但要**先分类**：

| 类型 | 判据 | 打法 |
|---|---|---|
| 血条型 | 敌方有有限 HP，能靠输出磨死 | 按 §2 四件判据打 |
| **结构型** | 敌方 HP ∞ / `win_on_boss` / 要凑击杀数 | **没有 `洞窟绳` 一律不打** |

`母舰空袭` 就是结构型：需要 210 点击杀输出（6 次击破 × 35 血），45 血进场必死。
实测 5 回合只磨掉 1 只，第 4 回合被四只敌人打脸 -31 直接穿。

**进精英房前先 `python tools/ai_play/ai_cli.py save`** —— `rewind` 只回到本场开打那一刻，
进了房就没有「换条路」的机会了。
