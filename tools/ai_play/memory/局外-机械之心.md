# 局外策略 · 机械之心

> **只读这一份就能做这一职业的全部局外决策。** 不依赖另一份。>
> **边界（写死）：本文件承载「离开战斗之后」的一切** —— 选卡、删卡、商店、附魔、
> 篝火、事件、奖励领取、路线、道具取舍。战斗内的操作与数值一律不写在这里。
> 版本 v2（2026-10-30）· 依据种子 `NNIZFPJ2LI` / `4PX0IX36DL` / `ZCVOQYYACI` / `ASRJWVB3FC` 四局 + `ZDB7OWVKE9`（打到第 2 层 n8 全灭）实战。

## 0. 默认口径

- **道具：能不放弃就不放弃**；但 `洞窟绳`（非 Boss 战可逃跑）是**T0，必须拿**。
- **商店购买顺序：删卡 → 补乘法件 → 附魔 → 其他。**
- 初始 13 张是 `攻击×5 + 木栅栏×5 + 构装体×2 + 升级×1`，**没有 0 费**。
  `素体` 靠 `机械核心` 与奖励来，是**层数载体**，**不能删**。
  → 删卡顺序：**多余的 `木栅栏`（先删到 2~3 张）→ 多余的 `攻击`（留 3 张）**。

## 1. 进层第一件事：读图，不是先点最上面的房间（v1 新增，最重要）

四局全灭的共同原因不是操作，是**没看地图就直接沿一条线冲**。
每层开局 `state` 会给出三段信息，必须全部读完再动：

1. `未走的房间（可规划路线用）` —— 房间 id + 类型（战斗/精英/商店/宝箱/事件/休息）
2. `连线（未走房间 + 当前房）` —— 邻接关系，这才是地图的真形状
3. `当前房间` 与 `巧克力`（每层 12，每走一格 -1）

### 读数三步法

1. **圈出所有「精英」**（一层 = 3 个精英简单 + 3 个精英困难，共 6 个）。它们是**墙**，不是目标。
2. **找出不穿墙的连通块**：沿着连线走，把不经过精英能到达的房间全部列出来。
3. **在连通块里排一条链**，优先级
   `商店 > 宝箱 > 事件 > 休息（血<60%）> 普通战斗`，步数 ≤ 巧克力余量。

### 实测实例（种子 `Z8CEIR2FOF`，一层 35 格 / 12 巧克力）

- 精英在 **n4 / n9 / n12 / n13 / n14 / n16**（n12-n13 还是一对相邻双精英，等于墙上的墙）。
- **不穿墙可达 18 格**：n31(起点) n30 n32 n23 n24 n25 n26(休息) n33 n34(商店)
  n17(商店) n18 n11 n10(事件) n3(事件) n2 n19 n20 n27。
- **锁在墙后的高价值点**：n0(大宝箱) 必须过 n9/n16；n6(商店)、n29(宝箱)、n28(休息)
  必须过 n4/n12/n13 或 n14/n16。
- → 正确打法：**先把 18 格里那条「n31→n30→n23→n24→n17(商店)→n18→n11→n10(事件)→n3(事件)」
  或「n31→n32→n25→n26(休息)→n33→n34(商店)」走干**，攒出乘法件，**再**考虑穿墙拿大宝箱。

> 结论：**机械之心一层完全可以一个精英都不打**。走满非精英链 = 2 商店 + 1~2 事件 + 1 休息 +
> 5~6 场普通战斗，足够养出侦察塔/激发/共享护盾。

## 2. 打精英前的资源盘点（v1 新增，硬判据）

**四件里少于三件，就不打精英，改走绕行路线。**

| 检查项 | 打精英的门槛 |
|---|---|
| 乘法件 | `侦察塔` + `共享护盾` + `集中突破` 至少 2 件；一件都没有 = 不打 |
| 每回合输出 | 场上单位攻击总和 ≥ 15（初始卡组只有 ~10） |
| 血量 | ≥ 70%（46/66）；低于 40% 直奔篝火，别想精英 |
| 逃生手段 | `洞窟绳` 在手，或已确认绕行路线存在 |

算不平就用 `flee` 走人 —— **逃跑不扣奖励进度，只是白走一格**，比掉 40 血划算。

## 3. 开局三件起始道具（v1 按实战改）

优先级：

1. **`洞窟绳`（非 Boss 战可逃跑）** —— 前期打不过精英时唯一的安全阀，**遇到必拿**
2. **`栅栏修复术`（栅栏叠合 0/6+0/6=0/9）** —— 直接加厚工事宿主，与 `升级` 乘法叠加
3. **`鸭之低语`（每回合随机费 +1 / 伤害 +1 / 多抽 1）** —— 运气好直接加速整局
4. 加最大生命（`类固醇` +10）
5. 纯金币（`行囊` +100 金 = 一次删卡或一张卡）

避免：只加成「技能伤害」的（这个职业靠单位）、需要「打很多技能」才生效的。

## 4. 三选一选卡优先级（v1 全部按实战重排）

1. **`侦察塔`** —— 每层改造让射程内敌人受伤 +1，改造流的伤害乘数。见到就锁
2. **`共享护盾`** —— 挂在工事上能把「7 点血」拖满一整场（实测）
3. **`集中突破`** —— 10 + 层数 ×4，实测 46 点；一发定胜负
4. **`批量传输` / `激发`** —— 层数 + 补牌 / 改造即输出
5. **`升级` / `加厚装甲`** —— 层数发动机，永远不嫌多
6. **宿主**（`构装体` / `素体` / 带改造奖励的单位）
7. 其他

**不拿**：纯伤害技能（除非 0 费或多段）、「需要很多小怪」的卡。
⚠️ v0 写的「改造牌一律最高优先」**是错的** —— 只有改造牌没有乘法件时，
输出仍是线性 +2，一层精英照样追不上（四局实证）。

## 5. 商店

1. **删卡** —— 先删 `木栅栏`
2. **买乘法件**（侦察塔 / 共享护盾 / 集中突破 / 批量传输 / 激发）
3. 附魔 —— 给宿主单位（构装体）附「生命 +」或「力量 +」
4. 升级最大生命 / 巧克力

## 6. 事件取舍

- 先拿好处，没好处才离开。
- 「删一张卡」→ 删 `木栅栏`。
- 「改造一张卡」→ **对机械之心是正收益**（白给一层）。
- 「复制一张卡」→ 复制 `升级` 或 `侦察塔`。
- 「给随机道具」→ 优先（可能抽到洞窟绳/乘法件）。
- 代价是最大生命：血 > 60% 可以吃。

## 7. 血量与巧克力

- 66 血，中间档。**没有乘法件之前不要碰精英**，那段最脆弱。
- 血 < 40% 直奔篝火（休息回 40%）。
- **巧克力是路线预算**：每层 12 格，把步数算清楚再走；走进死胡同 = 白扔一个房间。

## 8. 卡组厚度

- 目标 **18~22 张**。四局里第 4 局卡组涨到 20 张、道具 5 件，是一层走得最远的一局。
- 但**单纯变厚不算变强**：奖励页优先拿乘法件，其次才是删卡，最后才随便拿牌。
- 同名牌超过 2 张基本是浪费（`攻击` 除外，前期靠它撑输出）。

## 10. 巧克力口径 + 第 2 层路线复盘（v2 新增）

**巧克力（已核对源码 `RunState.advance`）**：

- 每层初始 = 12（难度 8 起 11）；第 2 层实测进场是 **9**，所以要看 `state` 的实数，别背常数。
- **走没走过的房间 -1；走回头路 0 消耗、不结算**（`path_to` 只允许穿已走过的房间）。
  → 路线可以「一去一回」，回程不吃预算，死胡同房（只有一条连线的）也能顺手吃掉。
- 扣到 0 → 置 `boss_pending`，**当前房间要先结算完**，回到地图才「入夜」打本层 Boss。
- **第 3 层不收步数**（`free_layer`），Boss 由「走到直道尽头的 Boss 格」触发。

**这一局的路线（能抄的部分）**：

- 一条链吃满价值：`宝箱 → 战斗 → 休息 → 精英 → 精英 → 大宝箱 → 精英 → 战斗`。
  **休息插在精英之前**，把 34 血抬到 45 再进精英 —— 这个顺序是对的。
- 拿到 `鹿首标本` 之后，普通战斗变成「拖到第 5 回合一发清场」，掉血反而更少。
  → **技能流道具（每回合技能 +N）优先级高于单位流道具**。

**奖励 / 宝箱顺位（第 2 层工厂线实测）**：
`批量传输`(8040) > `量产型谟涅摩叙涅`(8075) > `集束炮台` > `改装者`(8076) > 宿主。
理由见战斗策略 §11「炮击引擎」—— 这三个 + `鹿首标本` 才是第 2 层的输出。

## 11. 第 2 层精英取舍（v2 新增，硬判据）

精英仍是唯一的高质量补强来源（v1 已证伪「全程躲精英」），但要**先分类**：

| 类型 | 判据 | 打法 |
|---|---|---|
| 血条型 | 敌方有有限 HP，能靠输出磨死 | 按 §2 四件判据打 |
| **结构型** | 敌方 HP ∞ / `win_on_boss` / 要凑击杀数 | **没有 `洞窟绳` 一律不打** |

`母舰空袭` 就是结构型：需要 210 点击杀输出（6 次击破 × 35 血），45 血进场必死。
实测 5 回合只磨掉 1 只，第 4 回合被四只敌人打脸 -31 直接穿。

**进精英房前先 `python tools/ai_play/ai_cli.py save`** —— `rewind` 只回到本场开打那一刻，
进了房就没有「换条路」的机会了。

## 12. 抓牌评分口径 v5（代码对齐版，2026-10-31）

### 12.1 为什么改：一票否决把牌路锁死了

v4 及以前口径是硬锁「先产聚能炮击、再拿配合卡」—— 产能没 ready 时配合卡只给
**5 分**（产能卡 130 分）。跑下来牌组永远是同一套，遇到不吃炮击的关只能绕，
而且**没机会发现别的强牌**：10 局下来 7 局死在一层，牌组仍然是那几张。

→ 改成三段打分，**任何卡都能被拿**，只是有偏好：

| 组成 | 规则 | 量级 |
|---|---|---|
| 类型基线 | 效果 52 / 技能 50 / 盟友 48 / 工事 45 / 场地 42 / 诅咒 4 | 定基调 |
| 文本关键词 | 造成伤害 +10、能量 +10、抽牌 +9、召唤 +9、生成 +8、回复 +8、护甲/嘲讽 +7 | 累加 |
| 费用曲线 | ≤2 费 +8 / 3 费 +3 / ≥5 费 −5 | 低费优先 |
| 稀有度 | 史诗+ +6 / 稀有 +4 | 小加成 |
| 体系协同 | 炮击产能 +16；增幅 ready +12、否则 +6；引擎链 +8~14 | **只加分** |
| 手册顺位 | 侦察塔 +22 / 共享护盾 +20 / 批量传输 / 激发 +10 / 加厚装甲 +8 | 见 12.2 |
| 探索 | 没拿过 +10；拿过 ≥3 次 −6 | **逼自己换牌** |

实测 290 张分布：min 28 / 中位 75 / max 113（最高与中位只差 1.5 倍）。

### 12.2 关键词评分算不出「乘法件」，必须靠手册补

实例：`侦察塔` 文本里没有「造成 / 伤害」这类词，只有「改造」+7 → **70 分**，
低于全卡表中位数 74，比一张普通 3 费盟友还低，永远轮不到它 ——
可它是「每层改造 → 射程内敌人受伤 +1」的乘法核心，手册钉为 T0。

→ **实战顺位要写进代码**（`mech_pilot.MANUAL_ORDER`），否则策略文件只是给人看的。
当前对齐后：聚能炮击 113 / 集中突破 107 / 激发 107 / 共享护盾 102 / 侦察塔 92。

### 12.3 商店：血量优先于卡

血 < 40% 时**先买「最大生命 +」**，再考虑卡。实测栽过一次：14/66 血进商店买了两
张卡，下一场直接被打死，卡还没捂热。

### 12.4 十局数据（2026-10-31，温和口径首轮）

- 32 场战斗：单场掉血 **平均 14.4 / 中位 5 / 最大 55**。
- 一半以上的战斗是 0~5 血；**每局总有一场掉 40~55 血**，那一场决定生死。
- 爆血关已定位：**「鸭子骑士来袭」**（两波制，见战斗手册 §13.6）两局各掉 33 / 37 血；
  同期「爆炎鸭阵」「夜鸭阵」「使魔鸭群」都是 **0 血**。
- 拿到的牌 20 种（改造工厂 / 集束炮台 / 聚能机兵 / 侦察塔 系 / 代达罗斯 /
  充电装置 / 能量屏障 / 批量传输 / 集体改造 / 榴弹击手 / 战斗骨骼 / 返修 / 改装者 /
  轻量化 / 淘汰 / 隐藏能源 / 重组 / 回响 …）—— 探索加分确实让牌路散开了。

→ **结论：抓牌种类不是瓶颈，「个别关爆血」才是。** 下一步优先做「进关识别 + 绕行」，
而不是继续调抓牌权重。

## 13. 数据口径：先确认 pilot 在正常推进，再看掉血统计

两个坑都吃过，都会把人带进错误的结论里：

1. **`snap["hp"]` 与战斗内 `state.self_hp` 不同步。** 判负后 `hp` 可能还显示进入战斗时的
   数值，于是出现「掉 0 血却回标题」。**判死因要看引擎的结算行**（bridge 的 state 里有
   `对局结束：失败（我方 HP 归零）`），不要看血量差。
2. **pilot 卡在同一回合里时，场地伤害（爆炎鸭阵等）根本没机会触发**，统计出来是「0 血」，
   这是假数据。修好回合纪律后同一关实测掉 59 血。

→ 结论：**「哪关爆血」这类统计，只在 `结束回合` 次数与局内回合数对得上时才可信。**

### 当前最好成绩（2026-10-31 晚）

| 指标 | 数值 |
|---|---|
| 最远 | **58 步**（未出第一层），摸到过一层 Boss｢远古虚骨龙｣ |
| 常见 | 20~36 步 |
| 死因 | 全部是「我方 HP 归零」，**没有一次是超时**（所有内置关 `turn_limit = -1`） |
| 卡组 | 12 局共拿到 25+ 种牌（探索加分生效），含手册 T0 的 侦察塔 / 共享护盾 / 集中突破 |

**瓶颈判定**：不是抓牌种类、不是路线选择，而是**开局牌组的伤害密度撑不住一层的血量税**
（5×木栅栏 6 血 + 5×攻击 4 伤，而篝火只回 40% 上限）。下一步要么换职业验证，
要么开局就把第一笔金币全砸「伤害卡」。

## 14. 掉血账本修正 + 11-01 六局数据（v6）

### 14.1 「掉 0 血」是记账假象，不是运气

`battle_scene.gd:7544` 只在**战斗胜利**时把 `RunState.hp` 写回 `engine.state.hp_self`；
**打输那场根本不写回**。而 `roam.do_battle` 原来 hp0/hp1 都取 `snap["hp"]`（= RunState.hp），
于是全灭那场被记成 `hp0 == hp1`、掉血 0 —— 一局的「总掉血」被系统性压低，
还让人误以为「一半战斗都是零伤」。

→ 现在：`hp0 = battle.hp_self`（战斗内真值），结算行含`对局结束：失败` → `hp1 = 0`。
修正后同一批局的真实掉血是 **71~142**，而不是之前账面上的 0~19。

### 14.2 六局实测（2026-11-01，机械之心，headless）

|---|---|---|---|---|
| DD7HWR2R12 | 13 | 全灭（鸭子骑士） | 53 | 53 |
| （随机） | 30 | 全灭（夜鸭阵） | 105 | 53（弓手与骑士） |
| ZLDVWW8JY7 | 40 | 全灭（白魔法鸭护阵） | 111 | ~49 |
| （随机） | 26 | 全灭（白魔法鸭护阵） | 86 | 31 |
| （随机） | 28 | 全灭（夜鸭阵） | 93 | 36 |
| （随机，修完空转） | **43** | 全灭（**Boss 远古虚骨龙**） | 119 | 54 |

**读法**：血池 66~76，一局却要交 80~140 的血量税，而篝火只回 40%
→ 数学上就活不到 Boss。**单场 30~55 的「困难普通关」是主要税源**，
它们全是 `TIER_NORMAL_HARD`：白魔法鸭护阵 / 鸭子骑士来袭 / 夜鸭阵 / 弓手与骑士。

### 14.3 下一步的两个方向（还没做）

1. **绕开困难普通关**：地图节点只有「战斗」这个粗粒度标签，看不出是 hard tier。
   要走这条路得先让 bridge 把 `pending_node` 的关卡 key 暴露出来（能读 key 就能按
   `white_mage_guard` / `duck_knight` 这类名字直接跳过）。
2. **把开局 150 金全砸伤害**：现在商店只在血 <40% 时优先买最大生命；
   实测血量税主要发生在前两场，**第一笔钱买卡比买血更划算**。

### 14.4 空转压到 27 次（原来 138）

138 → 27，`连点 4~6 次`（旧故障特征）22 → 2。步数也从 30~40 抬到 43~52。

## 15. 血量的三个口径 + 事件才是隐形税（v7，2026-11-01 十二局）

### 15.1 血量有三个数，混用一次就误判一次

| 口径 | 取法 | 什么时候可信 |
|---|---|---|
| `snap["hp"]` = `RunState.hp` | 局外真值 | 战斗**外**随时可信；战斗内只在**胜利**后被写回 |
| `battle.hp_self` | 战斗内真值 | 战斗内随时可信 |
| 「对局结束：失败」检测 | `ai_cli.state()` 文本 | 判死因用 |

实测同一场并排打印（`⚑ 本场账：局外 76→50 ｜ 战内 76→50`）：**两者是同步的**，
唯一的例外是打输那一场 —— 局外不写回（`battle_scene.gd:7544` 只在胜利时回写），
于是 `局外 30→30 ｜ 战内 30→0`。所以：**hp0 取战内、失败场 hp1 记 0**，这样才对。

⚠️ 另一个坑：**撤退**走 `return snapshot()`，进战前后取到同一份状态 → 账面上是
「掉 0 血」，和「零伤通关」长得一模一样。现在 `fled` 单独标记，且 `lost` 照常算
（撤退前掉的血是实打实的，s2 实测「52→13」= 掉了 39 才撤，记 0 会把一局总掉血
低估一半）。

### 15.2 事件是隐形税，比一场战斗还贵

一局实测：`走进 事件（血 53%）` → 连过四个事件 → `走进 事件（血 21%）`，
**一场架都没打，血掉了 32**。原因全在选项上（`失去 12 点生命` 这类）。

原 `EVENT_AVOID` 只有 4 个词（鸭之低语 / 源数之力 / 失去 5 点最大生命 / 锻造），
而 event_scene 里真正写的是「失去 %d 点生命」「失去 21 点生命」—— 一条都没挡住。
现在：**`失去` + `生命/HP` 一律避开**（单纯失金币照拿，钱不值钱）；
所有选项都要付代价时，挑掉血最少的那个。

修完后同一批局的事件段：`安全选项 进行占卜`、`好选项 你会需要它（获得道具「泉水」）`、
`好选项 打开宝箱（获得卡牌奖励）` —— 事件**不再扣血**。

### 15.3 十二局实测（headless，机械之心）

| 阶段 | 步数 | 单场掉血区间 | 典型死因 |
|---|---|---|---|
| 修 cancel 前 | 15~43 | 30~43 | 白魔法鸭护阵 / 骑士冲锋 |
| 修 cancel + 集火 + 事件后 | 17~29 | **5~29** | 巫师的召唤 / 白魔法鸭护阵 |

**单场掉血从 30~43 压到 5~29**，是这一轮最实在的进步（血池 66~76，篝火回 40%，
单场 30 = 三场必死，单场 15 = 能撑六场）。

高频杀手（12 局统计）：`骑士冲锋` 4 次、`白魔法鸭护阵` 3 次、`巫师的召唤` 2 次。
其中 **骑士冲锋 = 3 只鸭子骑士（各 30 血 / 3 攻 / 程 1 / 速 2，血池 90）**：
速 2 × 3 只 = 每回合 18 伤，开局牌组每回合只能出 8~12 伤 → 6~9 回合才清得完，
数学上必死。**这关不是操作问题，是卡组强度的硬门槛。**

### 15.4 抓牌口径 v7：没有源的时候，放大器是废纸

实测两局：
- e1 拿到「集束炮台×1、升级×1、代达罗斯×1、谟涅摩叙涅×1」
- e2 拿到「集中突破×1、升级×1、**谟涅摩叙涅×2**」

e2 全程**没有一张炮击源**，却拿了 2 张「谟涅摩叙涅」（炮击每张 +7 的放大器）。
它 0/10 身材，占着手牌什么都不产出。原口径 `AMP: +12 if ready else +6` 让这类
空转件**永远有正分**，几局下来牌库全是配合件、没有一个引擎。

现在：
- 炮击源（`CANNON_SRC`）：一张源都没有时 **+26**（原 16），有源 +16 —— 先有产出
- 放大器（`CANNON_AMP`）：ready **+12** / 有 1 个源 **+6** / **一个源都没有 −16**

### 15.5 还没解决的（下一轮）

1. `骑士冲锋`（3×速 2 骑士）确实打不过，只能靠卡组强度或避开 —— 但地图不暴露关卡名。
2. 木栅栏「手上有 2 张、hints 写着可出、点了没反应」仍然偶发，`my_space()` 只数
   「9 格里有没有空」，没算引擎的落格限制。
3. 篝火只回 40%，是血量的主要补给；目前 `node_score` 血 <55% 时篝火 100 分最高，够用。

## 16. 牌库稀释才是真瓶颈（v8，2026-11-01 十局对照）

### 16.1 商店不删牌 = 每回合自带两张废牌

开局牌组 12 张：**5×木栅栏（2 费 0 攻）+ 5×攻击（1 费 4 伤）+ 素体 + 构装体**。
每回合 5 费、抽 5 张 → 手牌里平均 2 张木栅栏，它们**不产出任何伤害**。
实测（y1 局）：一局 14 回合打出 29 张攻击 = 116 伤，摊下来 **8.3 伤/回合**，
而一层普通关血池 60~90 → 一场要打 10 回合以上，对方每回合 3~5 伤，
**一场就是 25~40 血**，血池 66~76 撑不过三场。

原来 `do_shop` 的 `BUY_SERVICES` 里虽然有「删除一张卡」，但**排在买卡之后**，
`budget=4` 每次都被新卡吃光 —— x1 局实测：28/76 血、握 215 金进商店，
买了 3 张新卡、**一张废牌没删**。

现在：`junk_left = 木栅栏数 + max(0, 攻击数 − 2)`，只要 > 0 且买得起，
**删卡永远排在买卡前面**；买卡门槛随牌库厚度上浮（`62 + 2×(牌库−16)`，上限 90），
牌库 23 张时门槛 76，逼它要么删牌要么攒钱。

删除优先序 `DELETE_ORDER = ["木栅栏", "攻击"]`：
`JUNK` 里的素体 / 构装体是 0 费小件、升级是体系件，**不能跟着删**。

### 16.2 十局对照（同一天，机械之心，headless）

| 指标 | 改前 41 局 | 改后 10 局 |
|---|---|---|
| 平均步数 | 25.1 | **32.4** |
| 最高步数 | 58 | **72**（y5，删了 3 张木栅栏） |
| 到过第二层 | 0 | 0 |

**删卡数与步数正相关**：y5 删 3 张 → 72 步；y6/y8 删 1 张 → 43/35 步；
一张没删的局全在 10~11 步就全灭。

### 16.3 但一层还是过不去，原因已经算清楚

`攻击` 只有 4 伤。一层普通关血池 60~90，敌方每回合 3~5 伤。
即使**每回合都把 5 费全打成攻击**（理想 20 伤/回合），也要 4~5 回合，
期间挨 15~25 血；实际只有 8.3 伤/回合 → 10 回合 → 挨 30~40 血。
血池 66~76、篝火回 40%，数学上走不到第一层 Boss。

所以下一轮不该再调 pilot 的点击逻辑了，只有三条路：
1. **多删**：一间商店只能删 1 张（服务限量），一层最多 3 间商店 → 最多删 3 张。
   要更快就得靠事件 / 卡组编辑节点（`do_deck_edit` 已有，但地图上很少）。
2. **拿高伤牌**：`card_value` 里「造成伤害」只 +10，实际应该按**伤害/费**排序
   （4 伤 1 费 = 4.0；聚能炮击 1 费 10+ 伤 = 10+）。
3. **让单位承伤**：木栅栏 0 攻但 6 血，挡在敌列前面能吃掉一回合伤害 ——
   现在 `lay` 只按「堵敌列」排，没有「这只墙能活几回合」的估算。

### 16.4 诊断口径新增两条

- **商店每次快照打印货位**（`· 商店快照 gold=… 废牌=…`）：删卡为什么不触发，
  看一眼就知道是「服务已售罄」还是「没认出 key」还是「钱不够」。
- **`act` 的 `ok`/`msg` 必须读**：日记里多次出现「提示写着可出、点下去没反应」，
  而服务端其实每次都回了 `ok` 和原因，之前一直没读 —— 现在 `_click` 里 `✗ … msg` 会打出来。

## 17. 一层 Boss 的进门判据：纯伤害总量 ≥ 100（v9，种子 `298C9I6UT9` 手动实测）

§16.3 只是说「输出不够」，这一局把它**量化**了：手动逐回合打完一层，
死在远古虚骨龙（12 攻 / 100 血 / 射 2 / 移 2 + `鸭子号角` 每 3 回合召一只 30 血骑士）。

### 17.1 硬判据（进门之前算一遍）

```
卡组里「一次性技能伤害」总量 = Σ(每张伤害牌 × 伤)   ← 不含单位攻击
要求：≥ 100（一层 Boss 血池）；
      有召唤型效果区（鸭子号角这种）时，再加 30/每 3 回合
```

这一局的实际账（21 张卡组）：

```
攻击 ×5 × 4  = 20
聚能炮击 ×2 × 9 = 18      （还得先有集束炮台才摸得到）
冲击炮 ×1    = 10
────────────────────
合计 ≈ 48   → 对 100 血 Boss，一轮牌库打不穿，必输
```

→ **不满足就别进 Boss 房**：宁可多绕一间商店 / 事件把伤害件补齐。

### 17.2 一层「伤害侧一件套」：`集束炮台` + 任意改造件

- `集束炮台`(9166) 2 费 / 25 金：入场塞 **2 张 `聚能炮击`**（1 费 **9 伤 + 抽 1**），
  **每次获得改造**再从卡组捞一张进手。
- 机械之心的改造件（`升级` / `辅助刃` / `集体改造` / `改装者`）本来就多，
  于是**改造 = 摸伤害**，这是没有 `侦察塔` 时唯一能把「层数」换成「伤害」的路。
- 商店 25 金优先级应排在删卡之后、附魔之前。**见到就拿，见到第二张也拿。**
- 站位必须是**后排**（`r5`）：Boss 射 2，放 `r4c1` 第二回合就被拆。

### 17.3 巧克力最后一格 = 补给格

本层巧克力归零后，**下一次移动直接进 Boss 战**（实测：巧克力 0 时点 `n15` 休息，
结果直接掉进「远古虚骨龙」）。所以：

- 最后 1~2 格**别赌精英 / 别走空商店**，拿去**篝火回血**或**商店补伤害件**。
- 这一局把钱花在「删卡 50 + 集束炮台 25」上没错，但 `巧克力+` 要 **80 金**买不起 ——
  **进店前先看巧克力余量**，少于 2 就优先留钱买巧克力，而不是删卡。

### 17.4 一条被证伪的旧观念

§1 的「机械之心一层可以一个精英都不打」仍然成立，但**躲精英 ≠ 能过 Boss**。
这一局全程没打精英，靠商店凑出侦察塔 + 无限装甲 + 集束炮台，
**依然没到 100 伤**。精英的价值不只是卡，是**它给的那一次奖励 + 金币**，
用来把伤害件补齐。下一轮口径：**非精英链走完若伤害总量 < 100，就回头打一个精英**。


## 18. 进层先查「非精英连通块里有没有商店」（v10，种子 `4WWO608DYW`）

§1 的读图三步法有个致命盲点：它把「商店」写成第一优先，但**没查商店是否可达**。

这一局一层 35 格、12 巧克力，三间商店 **n6 / n19 / n34 全部在精英后面**：

```
n19 ← n18(精英)          n6 ← n12 ← n19 ← n18(精英)
n34 ← n33(精英) ← n26/n32
```

非精英连通块（23 格）里**一间商店都没有**。结果：
- 全程金币从 150 涨到 **390，一分没花出去**；
- 一层只靠「2 宝箱 + 2 事件 + 2 篝火删卡」凑伤害件，**Boss 前伤害依然不够**。

### 18.1 读图增加第 4 步（硬性）

> 圈完精英、排完连通块之后，**先数一遍连通块里有几间商店**。
> 0 间 → 这一层**不能**指望「商店补伤害件」，必须把期望压在
> `宝箱 + 精英奖励 + 事件` 上；钱要么原价买巧克力，要么就认了它花不掉。

### 18.2 金币也是有上限的资源

「金币多 = 强」是错的。**没有商店的金币等于 0**。
若连通块里商店 ≤1 间，`删卡` 的机会就只有篝火那一次（本局用了两次删卡：开局失忆药水 + 两处篝火），
卡组厚度压不下来，`木栅栏` 一直占着手牌位。

### 18.3 本局账（手动逐回合，供对照）

| 关卡 | 回合 | 掉血 | 备注 |
|---|---|---|---|
| 爆炎鸭阵 | 4 | **0** | 爆炎鸭亡语炸骑士，白赚 20 伤（见战斗 §20.4） |

——「巫师的召唤」零掉血就是证据——但**一层走到 Boss 前血只剩 25**，
再强的引擎也没有 5 个回合的时间去转起来。

换不起就第一时间把 `护盾生成器` / `铁栅栏` 立在**射程内当靶子**，
而不是让它直击 HP。
