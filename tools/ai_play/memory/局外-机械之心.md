# 局外策略 · 机械之心

> **只读这一份就能做这一职业的全部局外决策。** 不依赖另一份。>
> **边界（写死）：本文件承载「离开战斗之后」的一切** —— 选卡、删卡、商店、附魔、
> 篝火、事件、奖励领取、路线、道具取舍。战斗内的操作与数值一律不写在这里。
> 版本 v0（2026-10-27 建立）· **尚未实战**，实战后按「修正记录」改。

## 0. 默认口径

- **道具：能不放弃就不放弃**。
- **商店购买顺序：删卡 → 附魔 → 其他。**
- **删卡优先删初始 0 费牌** —— ⚠️ 机械之心初始卡组里有 `素体` 吗？
  初始 13 张是 `攻击×5 + 木栅栏×5 + 构装体×2 + 升级×1`，**没有 0 费**。
  `素体` 是靠卡效果/奖励拿到的，且它是**核心材料**，**不能删**。
  → 本职业的删卡顺序：**多余的 `木栅栏` → 多余的 `攻击`**。

## 1. 开局三件起始道具

优先级：

1. **给「改造」机会的**（额外改造牌 / 每回合免费改造）—— 直接加速核心循环
2. **给费用的**（`升级` 2 费，一回合只能打 2~3 张，费用就是命）
3. **加最大生命**
4. 一次性伤害（留给精英/Boss）
5. 纯金币

避免：需要「打很多技能」才生效的、以及只加成「技能伤害」的（这个职业靠单位）。

## 2. Ban 卡

优先 ban **纯技能/纯效果**的高费卡（4 费以上）。
**不要 ban 盟友/工事** —— 它们是改造宿主。
`升级`、`加厚装甲` 这类改造牌永远不 ban。

## 3. 路线优先级

```
商店 > 宝箱 > 事件 > 休息（血 < 50%）> 普通战斗 > 精英
```

- **商店第一**：删掉多余木栅栏，卡组越薄，越容易连续抽到 `升级`。
- 精英：血 > 70% 才打（主宿主还没养起来时打精英很危险）。
- 第三层直道：起点**回满血**，一定要踩。

## 4. 三选一选卡优先级

1. **改造牌**（`升级` `加厚装甲` 再来一张 / `无限装甲` / `自我修复`）
   —— 每多一张改造，主宿主就多一层
2. **自带改造奖励的宿主**（`战斗骨骼` `素体`）
3. **场地**（`改造工厂` `维修间`）—— 被动成长，非常契合
4. **费用回复**（`黑暗祭坛` 式的「攻击时回费」对机械之心也很好）
5. **厚血盟友**（`构装体` 再来几张）
6. 其他

**不拿**：纯伤害技能（除非 0 费）、需要「很多小怪」才强的卡。

## 5. 商店

1. **删卡** —— 删 `木栅栏`
2. **附魔** —— 优先给**宿主单位**（构装体/战斗骨骼）附「生命 +」或「力量 +」，
   注意：附魔是给**卡**的，改造是**战斗内临时**的，两者叠加
3. 买**改造牌**
4. 升级最大生命 / 巧克力

## 6. 事件取舍

- 先拿好处，没好处才离开。
- 「删一张卡」→ 删 `木栅栏`。
- 「改造一张卡」（鸭鸭工匠）→ **对机械之心是正收益**（等于白给一次改造）。
- 「复制一张卡」→ 复制 `升级` 或宿主。
- 代价是最大生命：血 > 55% 可以吃。

## 7. 血量管理

- 66 血，中间档。**主宿主养成之前不要乱打**，那段最脆弱。
- 血 < 40% 直奔篝火。
- 巧克力（体力）别见底。

## 9. 从战斗记忆迁入的局外条目（R419）

这几条此前误写在战斗记忆的跨职业注释里，按边界迁到这里。**都是「进战斗之前就该定好」的事。**

- **卡组厚度：目标 18~22 张。** 每回合抽 5 张，36 张 = 7 回合抽干，之后全靠运气；
  同名牌超过 2 张基本是浪费。奖励页**优先拿「删卡」而不是「选卡」**。
- **篝火：血 ≥60% 拿 `烤肉`，<60% 选休息。**
  `烤肉` 进 Boss 房自动消耗并补到上限（实测 61/80 → 80/80），不会浪费；
  休息只回 40% 且会被血上限吃掉，血高时等于白选。
- **附魔「伤害 +N」优先给多段技能**（龙息、流星雨这类按次数结算的），收益被段数放大；
  给单体技能只能加一次。
