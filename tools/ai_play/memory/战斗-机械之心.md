## 0. 这个职业的胜负手

机械之心是**养一个大怪**：初始 66 血，初始卡组
`攻击×5 + 木栅栏×5 + 构装体×2 + 升级×1`（**没有基础盟友**），赠品 `机械核心`。

核心循环：
1. `素体`（0 费 1/1）**回合结束不会被丢弃** → 能一张张攒在手里；
2. `升级`（2 费）改造一个己方盟友/工事：**+2 攻 / +10 血**，可**反复改同一张**；
3. 被改造的卡若自带改造奖励（`素体` +1 血、`战斗骨骼` +2 攻 +2 血）→ **额外再加**。

所以胜负手就一句：**把 `升级` 反复砸在同一个单位上**，养出一个对面打不动的巨块。
一条重要提醒：**改造加成只在它在场上时有效**，被打破后回到牌里的是原卡 ——
所以「养成了就不要让它死」，该后撤就后撤。

## 1. 关键卡

| 卡 | 费 | 作用 |
|---|---|---|
| `素体` | 0 | 0 费 1/1，**不弃**，可攒；被改造 +1 血 |
| `构装体` | 3 | 3/8 厚身板，白板但耐打，适合当改造宿主 |
| `升级` | 2 | **+2/+10**，可无限叠。全场最重要的一张 |
| `战斗骨骼` | 2 | 被改造时 **+2 攻 +2 血** —— 最佳宿主 |
| `改造工厂` | 2 | 场地：站上去每回合结束 +1/+1，**无限叠** |
| `维修间` | 1 | 场地：自己人每回合回 **4 血** |
| `加厚装甲` | 1 | 只吃盟友，**生命 +4**，算一层改造（会触发各种「每层」光环） |
| `无限装甲` | — | 每回合供一张 0 费改造牌 |

## 2. 每回合的固定检查清单

1. **宿主还在场上吗？** 在 → 优先保护它（后撤 / 用栅栏挡）。
2. **有 `升级` 吗？** 有就打在主宿主上（同一个目标反复改，别分散）。
3. **`素体` 攒够了吗？** 素体 0 费，**随时可以打**；但留在手里也有价值
   （它们不弃）。判断：**场上需要一个挡刀的 → 打出去；否则留手里当改造材料**。
4. **场地要摆吗？** `改造工厂`/`维修间` 放**自己后排**（敌人进不去）。
5. **攻击**：场上单位能打就打（免费伤害）。
6. **结束回合**：`改造工厂` 会结算，`素体` 不弃 —— 这两件事每回合都在推进，
   所以机械之心**回合数就是资源**，不急着结束战斗。

## 3. 站位

- 主宿主放**第 3 行**（前排）才挡得住；但对面伤害高时退到第 4 行。
- `改造工厂` / `维修间` 放**我方最后一行**（第 6 行，敌人永远进不去）。
- `素体` 是炮灰，可以放最前面挡刀 —— 死一个换一回合是赚的。

## 4. 打特定敌人

| 敌人特征 | 应对 |
|---|---|
| 高攻单体 | 宿主血厚，能硬吃；配合 `维修间` 每回合回 4 |
| 群小怪 | `素体` 铺场挡刀，宿主专心长 |
| 会破坏单位的效果 | 宿主一旦被打死，投资全废 → **该后撤就后撤** |
| 高血 Boss | 这场要打很久 → 优先 `改造工厂` 无限叠 + 每回合稳定 `升级` |

## 5. 什么时候该 SL（rewind）

`python ai_cli.py rewind` 回到本场开打那一刻。

- **主宿主（已经吃了 2 次以上改造）被打死** → 立刻重开（投资归零，基本打不回来）。
- 第 3 回合还没铺出任何宿主 → 重开（起手太差）。
- 掉血 > 55% 且场面没优势 → 重开。
- 赢了但掉血 > 60% → 重开。
- **不要**因为「前两回合没打出东西」就重开 —— 这个职业本来就慢。

## ✱ 跨职业通用经验（R418 · 森林精魄实战迁移，注释体，未在本职业验证）

> 以下几条是别的职业打出来的**与职业无关**的规则。本职业实战前先读一遍，
> 能省掉一整轮踩坑。

<!-- ✱ -->
1. **`rewind` 会吞掉消耗型道具的收益。**
   例：吃过「烤肉」再 `rewind`，血不会回到 +25% 的那个值，而是回到吃之前。
   → 要 SL 就在**进 Boss 房之前** `save` + `cp` 备份 `.sav`，出事用 `load`；
   局内 `rewind` 只适合「还没吃任何消耗品」的战斗。
<!-- ✱ -->
2. **召唤失调是真的：刚放下的单位当回合只能移动、不能攻击。**
   状态栏仍会写 `[可行动×1]`，点它却只列移动格 —— 别被这行字骗了。
   → 「解场单位」要**提前一回合预铺**；当回合急需伤害只能靠技能牌。
<!-- ✱ -->
3. **判断一张牌能不能打，看「可点目标」列表，不要按卡面文案想当然。**
   相当一部分伤害技能受「半场 / 行列」限制：
   有的只能点己方两行、有的能多够一行、有的只列个别格子。
   按文案算出「我能打到 Boss」然后打空，是最常见的浪费时间方式。
<!-- ✱ -->
4. **血量劣势时的正确方向是「压缩回合数」，不是补血。**
   翻盘顺序：先落地**乘法件**（对全卡生效的加成，如伤害 +N / 费用 -1），
   再打**一次性核弹**（吃满费用的伤害牌），最后用**冰封 / 削弱 / 嘲讽**买回一整回合。
   补血只延长死亡时间，不改变「你打不死它」这个事实。
<!-- ✱ -->
5. **「接通」是伤害转移，不是免疫。**
   接通单位会替目标挡掉伤害；接通单位死了，下一只召唤物会立刻接上。
   → 面对这种机制，「先清小怪再打 Boss」是死循环，只能**攒一波爆发直接越过血线**。
<!-- ✱ -->
6. **每回合把费用打满。** 这条听起来废话，但两个 Boss 的失败局全是这么输的：
   留着 2~3 费没牌可打 → 敌方多活一回合 → 它的滚雪球效果（每回合 +力量 / 召唤）
   把你淹掉。宁可打一张废牌，也别留费。
