## 0. 这个职业的胜负手（v1 重写）

初始 66 血，初始卡组 `攻击×5 + 木栅栏×5 + 构装体×2 + 升级×1`（**没有基础盟友**），赠品 `机械核心`（每战开场塞 2 张 `素体`）。

v0 的结论「把 `升级` 反复砸在同一个单位上养出巨块」**实战不完全对**：`升级` 一次 +2/+10，
一层精英动辄 115~126 血、每回合 12 伤，只靠 +2 攻线性堆叠，**数学上追不上**。
真正的胜负手是**改造层数 × 乘法件**：

1. **改造层数**是计量单位（`升级` / `加厚装甲` / `批量传输` 各记一层）；
2. 乘法件把这个层数变成伤害：`侦察塔`（每层改造让射程内敌人**受伤 +1**）、
   `激发`（每次改造对随机 2 敌 **3 伤**）、`集中突破`（**10 + 层数 ×4**，实测打出 **46**）；
3. 于是「改得越多」不再是养成，而是**直接把伤害放大**。

> 一句话：**没有乘法件的机械之心 = 慢速白板，打不过一层精英。**

### 1.1 `升级` 打给谁（v1 修正）

- **工事也吃 `升级`**：木栅栏 0/6 → **2/16**，可叠合后更厚。**但栅栏 `射程 0`，
  改造出的 2 攻没有任何可打目标**（`有效范围 = 只覆盖自己那一格`）。
  → 这是**规则正确行为，不是 bug**，别再去查代码、也别指望它反打。
- 所以工事升级只买两样东西：**厚度（挡刀）** 和 **改造层数（喂乘法件）**。
  真正输出永远来自盟友（构装体 / 素体改造后）。
- **屏障判断**：想把栅栏养成墙，就配 `共享护盾` —— 挂在栅栏上，敌人打我方任何单位都先砍栅栏。

## 2. 每回合的固定检查清单（v1）

1. **先算这回合能出多少伤**：场上单位攻击总和 + 本回合能打出的技能伤害。
   **低于敌方每回合输出的一半 → 这场属于「打不赢」，别再投入，准备 `flee`/结束。**
2. **乘法件先落地**：`侦察塔` 上场 > `侦察塔` 升级 > 一切。它一落地，后面每层改造都变伤害。
3. **改造层数打满**：`升级` / `加厚装甲` / `批量传输` 全打出去，别攒 —— 层数是乘法件的燃料。
4. **`素体` 打不打**：场上缺挡刀 → 打出去；否则留手里（0 费不弃，是层数载体）。
5. **`集中突破` 留到最后**：等本回合层数都堆完再打，差 1 层就是 4 点伤害。
6. **攻击不花钱，能打就打**（每回合先结算单位攻击，再考虑出牌）。
7. **结束回合**：`改造工厂` 结算、`素体` 不弃 —— 机械之心回合数就是资源，
   但在**赢不了的局里多拖一回合只是多掉血**。

## 3. 站位

- 输出宿主（改造过的构装体）放**第 3~4 行**，够得着就尽量靠后。
- `侦察塔` 放**最后一行**（射程覆盖自己半场 + 敌前排即可），别送。
- `共享护盾` 挂在**最后排的工事**上，不要挂在会死的单位上。
- `素体` 是炮灰兼层数载体，放最前面挡刀。

## 4. 打特定敌人

| 敌人特征 | 应对 |
|---|---|
| 高攻单体 | 共享护盾 + 厚工事硬吃 |

## 5. 精英/Boss 的「能不能打」判据（v1 新增，最重要）

进战斗后**第 1 回合结束前**做这道算术，不要打到第 5 回合才发现追不上：

```
需要的每回合输出 = 敌方总血量 / 你能撑住的回合数
你能撑住的回合数 ≈ 当前 HP / 敌方每回合总伤害
```

实测两组（机械之心，初始卡组，无乘法件）：

| 关卡 | 敌方构成 | 总血 | 每回合伤害 | 我方输出 | 结论 |
|---|---|---|---|---|---|
| 鸭子队长登场 | 队长 6/55 **双动** + 骑士 30 ×2 | 115 | **12** | ~10 | 5 回合死，**追不上** |
| 哈气骑士团 | 3 骑士 + 2 弓手，第 3 回合起双动 | 126 | 12→更多 | ~10 | **追不上**，且越拖越差 |

→ **判据：`每回合输出 × 可撑回合数 < 敌方总血` 就别打**，用 `flee`（`洞窟绳`）离开。
装备了侦察塔/激发/集中突破之后，同样的关卡输出能翻到 25~46，才进入可打区间。

## 6. 什么时候该 SL（rewind）

`python ai_cli.py rewind` 回到本场开打那一刻。

- **第 1 回合的算术就不通过（§5）** → 立刻 `rewind` 或 `flee`，别浪费 5 回合血量。
- **主宿主（吃了 2 次以上改造）被打死** → 投资归零，重开。
- 第 3 回合还没铺出任何宿主 → 重开（起手太差）。
- 赢了但掉血 > 60% → 重开。
- **不要**因为「前两回合没打出东西」就重开 —— 这个职业本来就慢。

## 8. 一层 Boss「鸭之暗面」（v2 实测，种子 Z8CEIR2FOF 被打穿）

**构成**：鸭之暗面 `12 攻（=9 基础 + 每存活暗杀者 ×3）/ 100 血 / 射 1 / 移 2`，外加开局 1 只
`鸭子暗杀者 6 攻 / 30 血 / 移 1`。敌方效果区 **`暗影召唤`**：每回合再召一只暗杀者。

**为什么这关是「拖不得」的**：Boss 攻击 = `9 + 3 × 场上暗杀者数`，移动也随之涨。
不杀暗杀者 → 第 3 回合 Boss 就是 **15 攻 / 移 3**，第 4 回合起一击能秒掉任何非超负荷单位。
全程实测：32 血进场，被咬到 8 血只用了 4 个敌方回合。

### 8.1 唯一稳的解：`共享护盾` + `旧式机兵`

`共享护盾`（0 费）：给场上一个盟友改造「我方 HP 受伤改由它承受」。
`旧式机兵`（3 费，**超负荷**）：生命降到 0 以下不立即死、**伤害不溢出**。
两者合体 = **玩家 HP 变成一条打不完的血条**（机兵吃负血，回合末才判死）。
→ 这是机械之心打多回合高攻 Boss 的**正解**，优先级高于任何输出牌。
备选：`护盾生成器`（接通，相邻己方受伤改由它承受）只能挡单位的伤，**挡不住打脸的伤**，不能替代。

### 8.2 这局输在哪（复盘）

1. **为了躲精英，全程只打普通战斗 + 休息** → 卡组只有 23 张、无乘法件、无 `共享护盾`，
   进 Boss 时每回合输出 ~10，Boss 100 血 = 需要 10 回合，而只能撑 3 回合。
   → **精英该挑着打**：`鸭子队长登场`（115 血/12 伤）确实打不过，
   但拿到 `侦察塔`/`共享护盾`/`集中突破` 之后的精英是**唯一的高质量补强来源**。
2. **没有靠挡刀换回合**：Boss `移 2~3`，会把「放在第 3 行的素体」直接绕过打脸。
   挡刀单位必须**贴着 Boss 落点**（它下一步能站到的格子旁边），否则等于没放。
3. **`木栅栏`（射 0）只买厚度和层数**，`升级` 砸上去变 3/19 也只挨一拳 —— 在 Boss 战里
   2 张 `升级` 换 1 回合是亏的，应该留给 `集中突破` 的层数。
4. **rewind 之后重复了同样的错误**：第二次仍按「素体顶前面」打，血量 32→17 只撑了 3 回合。
   → 进 Boss 前先看手牌：**没有 `共享护盾`+`旧式机兵` 或 `侦察塔`+高层数，就别指望磨赢**。

### 8.3 判据补丁（接 §5）

对「每回合自我强化」的 Boss（暗影召唤 / 招小弟加攻），§5 的算式要加一项：

```
敌方每回合伤害会涨 → 用「第 3 回合的预计伤害」代入，不要用第 1 回合的
可撑回合数 = HP / 第3回合伤害
```

`鸭之暗面`：HP 32 / 15 ≈ **2 回合** → 需要 `100 / 2 = 50` 每回合输出才成立。
没到 50 就别打了，先去补 `共享护盾`/`侦察塔`。




## 9. 第二层精英「母舰空袭」（v3 实测，种子 `ZDB7OWVKE9` 全灭）

**构成**：母舰 9208（0 攻 / 60 血 / 射 0 / 移 0）+ 量产型阿尔戈斯 9142（7/35 射 2 移 2，中排）
+ 量产型阿斯克勒庇厄斯 9207（7/50 射 1 移 1）×2 顶前排。敌方效果区 `空袭`（9209）。

**这是「结构型」关卡，不是血条关卡：**

| 机制 | 数值 | 对策略的含义 |
|---|---|---|
| 母舰**免疫所有伤害** | —— | 打脸无效；溢出伤害也不进母舰 |
| 每有一只**敌方**单位被击破 | 母舰 -10 血，并在它旁边补一份**同款满血复制** | 60 ÷ 10 = **必须击破 6 只**，且是打不完的循环 |
| 母舰被破坏 | **立刻通关**（`win_on_boss`） | 唯一胜利路径 |
| 敌方 HP | **∞** | 不能直击血条，也不能「打空某一条线」 |
| `空袭` | 玩家回合开始标 5 格 → 敌方回合开始，标记格上的我方单位各吃 10（每轮 +2：10/12/14…） | 空响**不**转打 HP；文本视图看不到标记 → 少铺场就少挨 |
| 阿斯克勒庇厄斯 | 每回合 +10 护甲；获得时**已有护甲**则力量 +1 | 实测 7→9→10→11 攻/回合，**拖 = 死** |
| 阿尔戈斯 | 命中我方单位后在敌方后排召唤「移速 +1 的俄倪厄」 | 射 2 会绕过第一排挡刀 |

**算术（§5 判据的第三档）：**

```
所需击杀数 × 最便宜的可复制单位血量 = 6 × 35 = 210
每回合要输出的量 = 210 / 可撑回合数
```

45 血进场、空场时敌方约 30 伤/回合（阿尔戈斯 7 + 俄倪厄 5 + 阿斯科 9 + 9）→ 可撑 1.5~3 回合
→ 需要 **70~140 每回合**输出。实测这套 30 张 / 45 血的卡组每回合只有 15~25，
**第一回合的算术就不通过**。本次 5 回合只磨掉 1 只（母舰 60→50）。

→ **没有 `洞窟绳` 就别进精英房；进了就只能靠进房前的 `save`。**

### 9.1 本节最重要的一条：不要在空场状态结束自己的回合

敌方单位走到第 4 行以后，**每一列没有挡刀就直接打玩家 HP**。四只一回合能打掉 30：
实测第 3 回合结束时我方单位被 `空袭` + 攻击清空，第 4 回合开打 HP 从 45 直接掉到 14（-31）。
→ 宁可留 0 费，也要在**每一列最前排**放点东西（1 血的 `素体` 也算，能挡一次攻击）。

### 9.2 这一局做对的地方（保留）

- 第 1~3 回合把伤害全压在**阿尔戈斯**（35 血，最便宜的可复制单位）上，方向正确。
- 用 `素体`（0 费）当挡刀、`木栅栏` 顶列，前两回合只掉 7 血。
- 失败点是「清完场后没有立刻补位」，不是开局。

## 10. 第二层其它实测关卡（v3）

- **量产流水线**（效果区 `流水线装配`）：后排一座量产型赫利俄斯（工事 6/30 射 1 移 0），
  **塔在场时，塔以外的敌方单位吃技能伤害减半**（向上取整），且每 3 回合再补一座塔。
  → 技能流**先拆塔**：`聚能炮击` / `攻击` 打塔不减半，打俄倪厄减半。
  实测 11 回合通关（45 血进场，剩 18）：`鹿首标本` 把炮击从 10 堆到 27，
  最后一发收掉 3 血的塔清空全场。
- **量产铁砧**（3 只量产型赫菲斯托斯 4/50）：`量产锻造` = 它**亲自击杀**我方单位时，
  在敌方半场锻出一只 45 血的俄倪厄，还带 `践踏`（击杀溢出沿列继续打）。
  → **严禁送小兵**，纯法术 + 嘲讽单位顶，实测 15 回合低损通关。
- **寒冰防线**：`鹿首标本` 生效后攻击 5 起、炮击逐回合涨，5 回合清场。

## 11. 炮击引擎（v3 新增，机械之心第 2 层的核心输出线）

三件合体才叫输出：

1. **`集束炮台`**（2 费 2/6）：入场把 2 张 `聚能炮击` 塞进抽牌堆；**每次被改造**再从卡组抓 1 张。
2. **`量产型谟涅摩叙涅`**（2 费 0/11 工事）：每回合一次，`聚能炮击` 伤害 **+7**，
   且因此抽到的那张费用 **-1**（实测变 0 费，可以连锁再打）。
3. **`鹿首标本`**（道具）：每回合技能 / 陷阱伤害 **+1**，全程线性叠加。

再配 0 费改造件：`辅助刃`（+2 力；打在 `机器鸟` 身上还抽 1 张）、
`批量传输`（手牌全体 +1/+4，抽 1）、`改装者`（入场全体 +4 血）、`升级`（+2/+10）。
→ 一张 `集束炮台` 一回合能吃 3~5 次改造 = 手上多 3~5 张炮击。
**这是唯一能在第 2 层追平「每回合 50+」的线**，见到就锁。

## 12. 铁律（速查）

1. **`rewind` 会吞掉消耗型道具的收益** → 要 SL 就在**进 Boss/精英房之前** `save` + 备份 `.sav`。
2. **召唤失调**：刚放下的单位当回合只能移动、不能攻击，别被 `[可行动×1]` 骗。
3. **判断一张牌能不能打，看「可点目标」列表**，不要按卡面文案想当然。
4. **血量劣势时的正确方向是「压缩回合数」**：先乘法件，再一次核弹，最后冰封/削弱买回合。
5. **「接通」是伤害转移不是免疫** → 先清接通单位再碰本体。
6. **每回合把费用打满**，宁可打废牌也别留费。
7. **`削弱` 类降攻牌是防御性价比最高的牌**（1 费换 14 点伤害豁免）。
8. **单体点杀需要场上有己方单位才有点目标** → 先铺场再点杀。
