# 局外策略 · 暗影刺客

> **只读这一份就能做这一职业的全部局外决策**（开局道具 / ban 卡 / 路线 / 选卡 / 商店 / 事件）。
> 不依赖另一份。>
> **边界（写死）：本文件承载「离开战斗之后」的一切** —— 选卡、删卡、商店、附魔、
> 篝火、事件、奖励领取、路线、道具取舍。战斗内的操作与数值一律不写在这里。
> 版本 v1（2026-10-27 建立）· 来源：玩法说明 + 卡池数据。实战后按末尾「修正记录」改。

## 0. 默认口径（新手友好，先照这个执行）

- **道具：能不放弃就不放弃。** 只有「装满了 / 装了明显害自己」才跳过。
- **商店购买顺序：删卡 → 附魔 → 其他。** 删卡优先删**初始 0 费**的牌。
- **血量是资源，不是命。** 该换血换血；只有「打完这层会死」才绕。
- ⚠️ 暗影刺客初始卡组**没有 0 费牌**（`终结` 是 0 费！）——
  所以「删初始 0 费」在这个职业上 = **删 `终结`**，但那是最强的收尾牌，**不能删**。
  本职业的删卡顺序改为：**多余的 `木栅栏` → 多余的 `攻击` → 多余的 `幽影`**。

## 1. 开局：三件起始道具怎么选

按价值排（看到就优先拿）：

1. **给费用的**（`黑暗领主` 系道具 / 任何「每回合 +费」）——暗影刺客吃费用吃到骨头
2. **给抽牌的**（每回合多抽 1）
3. **直接加最大生命**
4. 一次性伤害道具（留给精英/Boss 用）
5. 纯金币

避免：需要「单位站场」才生效的道具 —— 本职业单位很少。

## 2. Ban 卡（禁用）

开局有 ban 名额时，优先 ban **高费大怪**（4 费以上、且不是技能）：
它们会挤掉宝贵的 0/1 费位置。**不要 ban 技能**，尤其是 0 费技能。

## 3. 路线优先级（地图）

```
商店 > 事件 > 宝箱 > 休息（血 < 50% 时才去）> 普通战斗 > 精英
```

- **商店排第一**：这个职业极度依赖「删掉废牌」把卡组压薄，
  13 张里 5 张木栅栏是可以扔的。卡组越薄，抽到 0 费技能的密度越高。
- **精英**：只在血量 > 75% 且卡组已经删过至少 2 张时才打（精英掉好道具）。
- **篝火**：休息回血（0 档 40% / 1 档起 25% 最大生命）或烤肉（进 Boss 战回 25%）。
  血 > 70% 时选**烤肉**，否则选休息。
- **第 9 列固定是休息层**，第 6 列固定是宝箱层 —— 路线规划时把它们当锚点。
- 第三层是 5 格直道：起点（**回满血**）→ 精英 → 商店 → 篝火 → Boss。
  **起点一定要踩**，那是终局唯一回血口。

## 4. 三选一选卡：优先级

按「对 0 费技能链的贡献」排：

1. **0 费技能**（`偷袭` `敲晕` `连环戏法` `回旋斩` `影袭` `怒涛` `终结` 再来一张）
   —— 每多一张，一回合能多打一张，`终结` 就多 1 伤
2. **抽牌引擎**（`准备` `极速` `回转` `拒绝命运` `潜伏` `不眠`）
   —— 手牌数量 = 连招长度
3. **剩余费用收益**（`地狱猫` `鲜血堡垒` `夜蚀` `黑暗扩散` `暗影之刃` `活力转移`）
   —— 只有 1~2 张就够，多了没用（大多数标了「效果区不叠加」）
4. **费用回复**（`地狱咏唱者` `黑暗祭坛` `契约签订者` `黑暗领主`）—— 很香但占场
5. **陷阱**（`落石陷阱` `穿刺陷阱` `冰霜陷阱` `冻结陷阱`）—— 防守用，1~2 张
6. 其他

**不拿**：4 费以上非技能、需要大场面才强的卡、纯防守工事（已有 5 张木栅栏了）。

## 5. 商店

三行货架（卡 / 附魔 / 服务）。**每次进店按这个顺序花**：

1. **删卡（服务行第一项）** —— 删 `木栅栏`。删一张 = 卡组薄一张 = 抽到 0 费技能的概率上升
2. **附魔** —— 优先给**技能**附「伤害 +」，本职业技能又多又便宜，收益最大
3. 买卡 —— 只买上面「选卡优先级」1~2 类的
4. 升最大生命 / 加巧克力 —— 剩钱才买

钱不够时：**永远先删卡**，再考虑别的。

## 6. 事件取舍

- 事件房的选项**先拿好处，没有好处才离开**。
- 看到「删一张卡 / 改造一张卡 / 复制一张卡」→ 全都要（对本职业都是正收益）。
  删卡删 `木栅栏`；改造/复制选 `终结` 或 0 费技能。
- 「遗忘之泉」（删卡）：删 `木栅栏`。
- 「鸭鸭工匠」（把一张卡锻造成 2 费铁栅栏）：**别选**，除非手上全是木栅栏 ——
  它会把一张好牌变成工事，对本职业是减益。
- 代价是**最大生命**的选项：血 > 60% 可以吃，否则跳过。

## 7. 血量 / 巧克力管理

- 巧克力 = 体力（每场战斗消耗 1，见 `巧克力 N` 字段）。到 0 会触发疲惫/开 Boss。
- **别让巧克力见底**：篝火、事件、商店都可能补。
- 本职业容错低（初始 60 血，是三个职业里最低的），
  **血量 < 40% 时不要再打精英**，直接找篝火/商店。

## 9. 从战斗记忆迁入的局外条目（R419）

这几条此前误写在战斗记忆的跨职业注释里，按边界迁到这里。**都是「进战斗之前就该定好」的事。**

- **卡组厚度：目标 18~22 张。** 每回合抽 5 张，36 张 = 7 回合抽干，之后全靠运气；
  同名牌超过 2 张基本是浪费。奖励页**优先拿「删卡」而不是「选卡」**。
- **篝火：血 ≥60% 拿 `烤肉`，<60% 选休息。**
  `烤肉` 进 Boss 房自动消耗并补到上限（实测 61/80 → 80/80），不会浪费；
  休息只回 40% 且会被血上限吃掉，血高时等于白选。
- **附魔「伤害 +N」优先给多段技能**（龙息、流星雨这类按次数结算的），收益被段数放大；
  给单体技能只能加一次。
