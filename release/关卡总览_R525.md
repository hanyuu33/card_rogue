# 关卡总览（R525）

数据源 `scripts/game_levels.gd`：由 `tools/dump_levels.gd` 导出 JSON，再由 `_leveltable.py` 排版——**本文件不含任何手写数值**，改关卡后重跑两步即可。

`builtin_levels()` 共 **37** 关；另有 **2** 关定义在代码里但不进任何抽取池——事件专属「洞穴」、彩蛋 Boss「恶魔鸭（复仇）」（定义总数 39）。

## 通用设定

37 关完全一致的部分（逐关重复写没有信息量）：

| 项 | 值 |
|---|---|
| 玩家生命 | **20** |
| 初始卡组 | `starter` |
| 回合上限 | 无（`-1`，打到一方倒下为止） |
| 抽牌堆洗牌 | 开局洗牌 |
| 敌方 AI | 开启 |
| 起手额外手牌 | 0 张 |

**敌方血条口径**：`(关卡基准 enemy_hp + 精英 10 / Boss 20) × 2`（`GameLevels.enemy_hp_of()`）——下表「敌方 HP」列是**结算后**的那条血条。

**敌方单位写法**：`名称 力/生/程/速`，`×N` = 同款几只；格子坐标只在代码里用，表中省略。

> **洞穴**（`cave_level()`，第 38 关）：只有「洞穴」事件选「探索」才进，地图的普通 / 精英 / Boss 池永远摇不到它；胜利后固定给传说卡「枭熊」。

> **恶魔鸭（复仇）**（`revenge_boss()`，第 39 关）：刻意**不**进 `builtin_levels()`，所以它既不出现在调试关卡菜单，也不在 `boss_pool()` 里。触发链是——**第一层 Boss 摇中「恶魔鸭」→ 50% 置位 → 第二层 Boss 被顶替成这一只**（`RunState._roll_boss`，`REVENGE_TRIGGER_CHANCE = 0.5`）。地图上的 Boss 名牌与实际进入读的是同一份结果，所以顶替后地图会直接写「恶魔鸭（复仇）」。
