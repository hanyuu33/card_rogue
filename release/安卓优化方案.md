# 安卓版优化方案（R186）

> 目标：让游戏在安卓触屏上可完整游玩，同时把「普适优化」落地到双端。
> 总原则：**电脑端行为零变化或纯收益**——凡可能改变电脑端体验的改动一律走平台/事件类型判断。

## 二、P0 安卓阻断项（本平台生效，PC 零变化）

### 2.1 返回键 → Esc（新 autoload `BackKey`）
- Godot 4.3 安卓返回键发 `NOTIFICATION_WM_GO_BACK_REQUEST`，且默认 `quit_on_go_back=true`（按一下直接退 App）。
- 做法：新 autoload `scripts/back_key.gd`
  - `_ready`：`get_tree().set_quit_on_go_back(false)` + `process_mode=ALWAYS`（菜单暂停时也要收）。
  - `_notification`：收到 GO_BACK → 标题界面 = 退出；其余界面 = 合成一个 Esc 键事件（`Input.parse_input_event`），走现有 Esc 层级（关浮层 → 开/关菜单），**不新增任何分支**。
- PC 影响：该通知桌面端永不触发，零变化。

### 2.2 触屏长按 = 右键（battle_scene）
- 只响应 `InputEventScreenTouch`（PC 鼠标完全不进这条路径）。
- 判定：按下 ≥0.5s、位移 <18px、未进入拖牌/拖棋盘 → 触发一次 `_on_right_click()`。
- 覆盖：专注取消、取消选中；鲸鱼之怒本就有「不选了」按钮，长按是第二口子。
- PC 影响：无触屏设备不产生 ScreenTouch 事件，零变化。

## 三、P1 普适性能优化（双端同收益）

### 3.1 悬停跟随场景：静止不重绘
以下场景的 `_process` 原来**无条件** `queue_redraw()`，改为「鼠标位置变化才重绘」：

| 场景 | 时间基动画 | 处理 |
|------|-----------|------|
| class_pick_scene | 无 | 鼠标移动才重绘 |
| relic_pick_scene | 无 | 鼠标移动才重绘 |
| replay_list_scene | 无（返回键悬停读实时鼠标） | 鼠标移动才重绘 |
| shop_scene | `_hint_t` 提示淡出 | 鼠标移动 **或** 提示淡出没播完才重绘 |
| deck_edit_scene | `_tween` 200ms 滑位 | 鼠标移动 **或** `_tween` 非空才重绘 |

视觉效果与原来逐帧重绘**完全一致**（鼠标不动时画面本就静止），PC 闲置 CPU/GPU 占用同步下降——纯收益。

### 3.2 地图呼吸脉冲：节流重绘
- map_scene `_process` 末尾无条件 `queue_redraw()`（驱动 `sin(_t)` 呼吸/脉冲）。
- 改为 R180 同款 45ms 节流（22fps，呼吸周期 0.5s 视觉依然平滑，战场已验证）。
- PC 影响：脉冲动画 60→22fps，R180 已认可该折衷。

### 3.3 reward_panel 打开时逐帧重绘 → 按需
- 面板 `_draw` 无时间基元素（hover/滚动/提及悬浮都有事件驱动重绘），逐帧重绘是历史遗留 → 移除，保留 `_replay_tick()`。
- 回归：smoke 奖励面板流程覆盖。

### 3.4 不动的部分（刻意保留）
- campfire（火光）、title（花瓣）、scene_fx（过场）、ui_toast/ui_pop（短时动画）、battle_scene（R180 已节流）——这些是真动画场景，逐帧重绘是必要的。

## R187 性能专项（已落地，回归全绿）

针对「卡死 / 速度慢 / 卡顿」的第二轮优化。**原则：纯性能项两端通用（零行为变化）；
凡有行为差异的一律 OS 门控、仅安卓生效。**

| 项 | 类型 | 适用端 | 说明 |
|---|---|---|---|
| `CardText.parse` 缓存 | 纯性能 | 两端 | 卡面富文本解析（词句归一+括号剥离+提及扫描）按输入串缓存，返回浅副本；上限 512 全清 |
| `CardFace.wrap_text` 缓存 | 纯性能 | 两端 | 逐字 `get_string_size` 折行是 `_draw` 最贵纯计算；键=字体实例+字号+宽度(1/4px 量化)+原文；上限 2048 |
| `Mention.scan` 缓存 | 纯性能 | 两端 | 提及扫描按文案缓存；`reset_cache` 一并清空；上限 256 |
| 脉冲重绘 45→90ms | 行为差异 | **仅安卓** | `OS.get_name()=="Android"` 门控；相位按 `_now()` 取，降采样不卡顿；PC 保持 45ms |

- 断言：test_engine R187 块（6 条：缓存一致/副本隔离/清空不伤缓存）+ smoke `_check_perf`
  （wrap_text 副本隔离 + `_pulse_ms` 平台值 + 节流窗口不重复重绘）。
- 基线：engine 2402✓（+6）/ reward 26✓ / replay 35✓ / bgm 31✓ / smoke 29。
- 复查结论（未动的项）：`UiAssets`/`CardFace._art_cache`/BGM 流本就有缓存；磁盘写入只在
  地图节点切换时发生，不在战斗热路径；剩余 `_process` 全部带门槛或为真动画驱动。
