### 1.1 编辑器设置（必须）

打开 Godot 编辑器 → **编辑器 → 编辑器设置 → Export → Android**，填写以下三项。Godot 导出时**不读环境变量**，必须在此显式配置：

```text
export/android/java_sdk_path = "C:/JDK17"
export/android/android_sdk_path = "C:/Android/Sdk"
export/android/debug_keystore = "C:/Android/debug.keystore"
export/android/debug_keystore_user = "androiddebugkey"
export/android/debug_keystore_pass = "android"
```

配置文件实体路径：

```text
C:/Users/Administrator/AppData/Roaming/Godot/editor_settings-4.3.tres
```

## 三、打包步骤

### 3.1 前置检查

每次打包前先跑回归：

```bash
cd D:/work/card_rogue
python _verify.py
```

基线（R169）：engine 2364 / reward 26 / replay 35 / smoke 29 全部通过。

### 3.2 清理旧产物

```bash
rm -f "D:/work/card_rogue/dist/DuckCardsRogue.apk"
rm -f "D:/work/card_rogue/dist/DuckCardsRogue.apk.idsig"
rm -f "D:/work/card_rogue/dist/DuckCardsRogue-signed.apk.idsig"
```

### 3.3 导出未签名 APK

```bash
"D:/work/card_godot_demo/Godot.exe" \
  --headless \
  --path "D:/work/card_rogue" \
  --export-release "Android" \
  "D:/work/card_rogue/dist/DuckCardsRogue.apk"
```

### 3.4 手动签名

当前 Godot headless 导出时无法自动调用 `apksigner`（报 `All located 'apksigner' tools ... failed to execute`），因此导出后需手动签名：

```bash
export JAVA_HOME="C:/JDK17"
"C:/Android/Sdk/build-tools/34.0.0/apksigner.bat" sign \
  --ks "C:/Android/debug.keystore" \
  --ks-key-alias androiddebugkey \
  --ks-pass pass:android \
  --key-pass pass:android \
  --in "D:/work/card_rogue/dist/DuckCardsRogue.apk" \
  --out "D:/work/card_rogue/dist/DuckCardsRogue-signed.apk"
```

### 3.5 验证签名

```bash
export JAVA_HOME="C:/JDK17"
"C:/Android/Sdk/build-tools/34.0.0/apksigner.bat" verify -v \
  "D:/work/card_rogue/dist/DuckCardsRogue-signed.apk"
```

期望输出包含：

```text
Verified using v1 scheme (JAR signing): true
Verified using v2 scheme (APK Signature Scheme v2): true
Verified using v3 scheme (APK Signature Scheme v3): true
Number of signers: 1
```

## 五、已知问题

1. **Godot 自动签名失败**  
   现象：`All located 'apksigner' tools in C:/Android/Sdk/build-tools failed to execute`  
   根因：headless 环境下未正确传入 `JAVA_HOME`/PATH，导致 `apksigner.bat` 找不到 java。  
   解决：导出后使用 `apksigner.bat` 手动签名（见 3.4）。

2. **旧 idsig 与新生成 APK 不匹配**  
   解决：每次打包前删除旧 `.apk.idsig` 文件。

3. **APK 内无独立 .pck 文件**  
   现象：解包找不到 `*.pck`。
   根因：Godot 4 安卓导出走 `assets/` 直装（`script_export_mode=2`），资源平铺进 APK assets 目录，
   双架构引擎库（armeabi-v7a + arm64-v8a）才是体积大头，属正常现象。
   解决：每次打包前删除旧 `.apk.idsig` 文件。

4. **导出预设的发布密钥库指向不存在的路径**  
   现象：`--export-release` 直接报「未在导出预设中正确设置『发布密钥库』」，7 秒内失败。  
   根因：`export_presets.cfg` 的 `keystore/release`（与 debug）指向 `C:/Users/Administrator/AndroidDev/keys/release.keystore` —— 那是另一台机器生成的密钥库，本机整个 `AndroidDev` 目录都不存在。  
   解决：把 preset 里 6 行 keystore 改到本机现有的 `C:/Android/debug.keystore`（`androiddebugkey` / `android`），与 3.4 手动签名同一把钥匙；改完导出通过。

5. **编辑器设置里的 Java/Android SDK 路径被清空**  
   现象：`--export-release` 秒失败，提示「编辑器设置中需要有效的 Java SDK 路径 / Android SDK 路径」，而 `C:/JDK17`、`C:/Android/Sdk` 明明都在。  
   根因：`editor_settings-4.3.tres` 里 `export/android/java_sdk_path` 与 `export/android/android_sdk_path` 变成空串（`debug_keystore` 也被重置回默认路径），属编辑器设置被重写/丢失。  
   解决：把三项按 1.1 节写回 `editor_settings-4.3.tres`（`java_sdk_path` / `android_sdk_path` / `debug_keystore`）即可，无需重装 SDK。

### 6. 导出版资源判存（R190 修复，重要）
- 症状：APK 里卡图全部不显示（编辑器/PC 正常）。
- 根因：`card_face.gd` 的 `art_for()` 用 `FileAccess.file_exists()` 判断 `res://assets/pics/<id>.png` 是否存在。导出包里**不含源 PNG**，只有 `.import` 文本 + `.godot/imported/*.ctex`，`FileAccess` 在包里恒为 false → `load()` 永不被调用。
- 修法：判存一律 `ResourceLoader.exists(path)`（它对导入资源在编辑器与导出包都正确），再 `load(path)`。`ui_assets.gd` 早有同款注释与写法，`card_face.gd` 是漏网之鱼。
- 注意：`user://` 存档读写不受影响（FileAccess 照常）；`cards.json` 等数据文件在包内是原样拷贝，FileAccess 可用。

### 7. 安卓图标键名（R190 修复，重要）
- 症状：R189 出的 APK 图标不是森林精魄头像，而是**卡背图**。
- 根因：preset 里写的 `package/icon`、`package/icon_foreground`、`package/icon_background` 是旧键名，**Godot 4.3 不识别**，全部静默忽略；导出回退到 `project.godot` 的 `application/config/icon`（当时指向 `assets/cardback.png`）→ 所有图标槽位被卡背填充。
- 4.3 正确键名（官方文档 EditorExportPlatformAndroid）：
  - `launcher_icons/main_192x192`（旧版图标）
  - `launcher_icons/adaptive_foreground_432x432`（自适应前景，需保留 alpha）
  - `launcher_icons/adaptive_background_432x432`（自适应背景）
  - `launcher_icons/adaptive_monochrome_432x432`（单色，可选，未配置）
- 当前配置：三键分别指向 `assets/ui/icon_android_legacy.png` / `icon_android_fg.png` / `icon_android_bg.png`（森林精魄头像方案）；`project.godot` 的 `config/icon` 也改为 legacy 图标兜底。
- 验收方法（不打新包也能查）：解包 APK 后 `res/mipmap-xxxhdpi-v4/icon_foreground.png` 应与 `icon_android_fg.png` 像素一致（R189 用 MSE 比对抓出卡背串图）。
