# 新手教程 R744：绑「初次体验」，不绑关卡

## 一句话

教程的判据是**玩家档案里的「看过没」**（`ProfileData.tutorial_seen`），不是关卡数据。
所以同一段教程在任何关卡、任何职业、任何一次随机地图下都只讲一次；换新档才会重新看到。

> 关卡数据里那套 `game_levels` 的 `tutorial: []` 数组、`GameLevels.CUE_*` 与战斗页的
> 引导条（`_tut_bar`）都是 R5x 时代的休眠代码，一条都没启用。R744 没有复用它，
> 只借了它的「高亮框几何」思路。

## 六条教程

| id | 讲什么 | 触发时机 | 高亮（cue） |
|---|---|---|---|
| `map_walk` | 地图怎么走 | 第一次进地图 | `map_player` → `map_reachable` |
| `map_choco` | 巧克力 = 行动力，见底进 Boss | 走格子讲完 | `map_choco` |
| `battle_basic` | 手牌 / 费用 / HP / 胜利条件 | 第一场战斗、第一回合、玩家回合且手里有牌 | `hand` / `cost` / `hp` / `enemies` |
| `battle_ally` | 盟友与工事怎么用 | 第一次手里出现 `kind` 为盟友或工事的卡 | `hand_ally` / `board_own` |
| `tool_place` | 放置型工具（拖到空格埋伏） | 第一次持有 `is_usable()==false` 的工具 | `tool_bar` / `board_own` |
| `tool_use` | 使用型工具（点一下结算） | 第一次持有 `is_usable()==true` 的工具 | `tool_bar` |

判据都只看**数据字段**（`kind` / `is_usable()`），不看具体是哪张卡、哪个 id ——
以后新增盟友、工事、工具，自动落进对应那一条，不用回来改代码。

## 三个文件各管什么

| 文件 | 职责 |
|---|---|
| `scripts/tutorial_script.gd` | **文案与步骤（唯一口）**。每条教程 = 页数组，每页 `{text, cue}` |
| `scripts/tutorial_overlay.gd` | 弹层：压暗挖洞 + 高亮框 + 羊皮纸对话框 + 卷卷头像 + 打字机 + 翻页 |
| `scripts/tutorial_director.gd` | 调度：查档案、连播、标记已读；headless 一律不弹 |

宿主场景（`map_scene.gd` / `battle_scene.gd`）只做两件事：
调 `TutorialDirector.play()/play_chain()`，并实现
`tutorial_cue_rects(cue) -> Array[Rect2]`，把语义名翻成**屏幕坐标**矩形。

## 三条实现上的硬约束（都是踩出来的）

1. **坐标要加舞台偏移**。弹层是 `CanvasLayer`，坐标 = 屏幕坐标；场景里算出来的
   棋盘 / 手牌矩形是 1280 舞台内的本地坐标，返回前必须 `+ position`。
   （HP 条例外：它挂在上层 HUD 的 `CanvasLayer` 里，`get_global_rect()` 已是屏幕坐标。）
2. **挖洞不能用「四条压暗矩形」拼**。多个洞（手牌 5 张 = 5 个洞）时会互相叠加，
   重叠处黑成一块；`CanvasItem` 又没有擦除混合模式。最终用**横条法**：按所有洞的
   上下边界切横条，每条里求洞的 x 区间再取补集 —— 任意多洞都精确。
3. **对话框要会躲**。高亮目标常常就在下半屏（地图下方的格子、战斗里的手牌一排），
   贴下沿会正好盖住在讲的东西。`_box_rect()` 会把顶部 / 底部两种摆法都算一遍重叠面积，
   挑小的那侧。

## 自己验排版（出图）

```bash
# 地图：第 N 页（没有 --tutpage 就是从第 1 页开始连播「走格子 → 巧克力」）
$GODOT --path . scenes/map.tscn -- --screenshot --shotwait 2.0 --tutdemo --tutpage 3

# 战斗：第 N 页 / 指定某一条
$GODOT --path . scenes/battle.tscn -- --screenshot --level 0 --shotframe 130 --tutdemo --tutpage 5
$GODOT --path . scenes/battle.tscn -- --screenshot --level 0 --shotframe 130 --tutdemo --tutid battle_ally
```

`--tutdemo` 的两个副作用要记住：
* 地图页：允许在 `--screenshot` 模式下弹教程（默认截图不弹）。
* 战斗页：**不暂停整棵树**（截图按帧号触发，一暂停帧号就不走了），且允许弹教程。

## 回归

`scripts/test_engine.gd` 末尾的 R744 段钉了六件事：六条文案都有正文、高亮语义名
都有场景认领、地图与战斗都调调度器、标记幂等、`unseen()` 语义正确、弹层三件要素都在。

⚠️ headless 下教程一律不弹（`TutorialDirector.disabled()`）。原因：它暂停整棵树，
而 smoke 里「关菜单必须恢复暂停」的用例正在测这个状态，弹层一进来就误红 ——
这与 `story_unlock_toast.gd` 的 headless 早退是同一个判法。
