# 音频素材署名登记表

> 每引入一首曲子，必须在此登记一行。
> 理由：曲库条款会变，署名信息散落在代码里将来无法追溯；署名也是多数免费曲库的合规要求。

---

## 填写规范

| 字段 | 说明 |
|---|---|
| 场景 | 挂载位置（标题 / 地图 / 战斗 / Boss / 事件 / 奖励 / 胜利 / 失败） |
| 文件名 | `assets/audio/bgm/` 下的实际文件名 |
| 曲名 | 原曲标题 |
| 作曲者 | 原作者名 |
| 来源库 | OpenTracks / 魔王魂 / PeriTune / 其他 |
| 授权 | CC0 / CC BY 4.0 / 站点自有许可 |
| 需署名 | 是 / 否 |
| 下载日期 | 记录以便回溯条款版本 |
| 来源链接 | 单曲页 URL |

## ⚠️ 合规红线

本工程所选素材**仅限游戏内音频播放**，禁止用于 AI 模型训练 / 微调
（OpenTracks、魔王魂等库均在条款中明确禁止 AI 训练用途）。

引入新曲前，请到来源库核对**当前**条款——条款可能已变更。
