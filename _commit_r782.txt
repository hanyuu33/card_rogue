R782：工具栏能看效果描述——电脑端悬浮 / 安卓端点一下都弹完整说明

用户口径：「在工具栏看不到工具的效果描述」→ 电脑端悬浮、安卓端点击都要能看到。

实现
- battle_scene 新增 `_tool_tip_slot`（鼠标压着哪个槽）+ `_tool_tip_anchor_slot()`
  （**唯一判据**：上膛期优先，否则看悬停）+ `_draw_tool_tip_panel()`。
- 面板画在槽**左侧**，版式与道具悬浮说明共用同一套常量与折行（`CardFace.wrap_text`），
  第一行是「工具名」加粗，正文是 `TrapData.desc`；右缘在上膛时让开「使用 / 丢弃」
  按钮栏 —— 那层是独立高层 CanvasLayer，压在它下面会被整块盖住。
- 电脑端：`_on_hover` 命中工具槽即显示；进出槽那一下立刻 `queue_redraw()`
  （敌方回合画面静止，脉冲节流不一定在跑，只改状态会「压上去半天才弹」）。
  进左栏信息区 / 满屏叠层时收起（`_clear_hover_state` 只在本来挂着时重绘一次，
  否则每次鼠标移动都重绘，会把安卓的节流打回每帧）。
- 安卓端：没有 MouseMotion → 点一下上膛（`_tool_use_arm`，2.6 秒）期间一直显示，
  用掉 / 丢掉 / 过期自动收；触摸与合成鼠标两条事件都验过。
- 出图参数 `--totemtip`（直接上膛版）；**不能**挂 `--tooldemo`，那个参数被
  `reward_panel` 认领，会弹「获得奖励」面板把工具栏整个盖住（R754 踩过，本轮又复现一次）。

验证
- `test_trap_input` 新增 ⑧f 共 7 条：悬停认得槽 / 悬浮即显示 / 图腾有名字与描述 /
  移开收起 / 安卓原生触摸序列点一下也显示 / 上膛过期收起。
- trapinput 77✓ 0✗，八套回归全绿。
- 截图核验：`--stonetool --toolarm` 与 `--totemtip` 两张，面板与「使用 / 丢弃」
  双按钮不重叠，图腾长描述折两行不溢出。
